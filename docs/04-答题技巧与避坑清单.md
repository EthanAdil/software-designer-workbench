# 04 · 答题技巧与避坑清单

## 一、上午卷时间分配（75 题 / 120 分钟）

| 时段 | 动作 | 目标 |
| --- | --- | --- |
| 0~40 分钟 | 第一遍：会做的直接做，不确定的标记 | 完成 55~60 题 |
| 40~70 分钟 | 第二遍：处理标记题，排除法 | 补到 68~70 题 |
| 70~95 分钟 | 第三遍：计算题重算、易混概念复核 | 确认前 60 题无误 |
| 95~115 分钟 | 答题卡核对，确认无漏答 | 全卷完成 |
| 115~120 分钟 | 留出 5 分钟机动 | — |

**核心原则**：**先拿确定的 60 分，再抢不确定的 15 分**。一道题超过 90 秒没有思路，立刻标记跳过。

## 二、答题顺序策略

1. **先做专业英语**：5 题独立成篇，读完就能答，适合开场热身（约 8 分钟）。
2. **再做软件工程、面向对象、数据库**：分值最高且判断快，先把基本盘拿稳。
3. **接着做组成原理、操作系统、数据结构**：计算题需要脑力，放在状态最好的中段。
4. **最后做网络、安全、标准、多媒体**：碎片记忆题，快速判断。

遇到"完全没印象"的题：用排除法删掉 2 个明显错误的，剩余凭第一直觉选，**不要反复改**（统计上第一直觉正确率更高）。

## 三、蒙题原则（用于完全不会的题）

| 场景 | 倾向 |
| --- | --- |
| 选项中有"一定""必须""所有""只能" | 多为错误项 |
| 两个选项语义完全相反 | 答案常在其中之一 |
| 涉及年限、位数的数值题 | 优先选"常见值"（20 年、50 年、128 位） |
| 概念辨析题 | 选表述最完整、最"学术"的一项 |
| 计算题选项差距大 | 先做量级估算，排除量级不符的 |
| 实在无法判断 | 统一选同一字母，别乱跳 |

## 四、机考操作要点

- 熟悉**标记、跳题、答题卡定位**三个功能，考前用模考系统练 2 次。
- 上午卷答完后**不要急着交卷**，剩余时间自动划给下午卷，先仔细检查。
- 下午卷是**文本框录入**，写完先自查拼写和编号。
- 机考不提供编程环境，代码题是"阅读 + 填空"，不是真跑代码。
- 草稿纸由考场提供，计算题务必写过程，便于回头检查。
- **中途不休息**，考前少喝水。

## 五、高频失分点 TOP 20

**概念类**

1. 耦合与内聚的高低方向记反（耦合越低越好，内聚越高越好）
2. 把"改善性维护"答成"改正性维护"（改善性占比最大）
3. 数字签名与加密的公私钥方向记反
4. 混淆 `include`（必然）与 `extend`（条件）
5. 聚合/组合的菱形位置与实心空心记错
6. 把"已定义级"与"已管理级"顺序记反（CMMI 3 级是已定义）
7. 逻辑独立性与物理独立性的映像记反
8. 进程"阻塞 → 运行"当成合法转换

**计算类**

9. 补码负端范围少算一个（-2^(n-1)）
10. 流水线加速比分母用错（应为流水执行时间）
11. Cache 平均访问时间漏掉"未命中时先查 Cache"那一段
12. 页面置换手算时忘记更新"最近使用"顺序
13. 哈夫曼 WPL 算成"权值和"而不是"加权路径长度"
14. 二叉树 `n0 = n2 + 1` 套用到多叉树
15. 子网可用主机数忘记减 2
16. 周转时间忘记减到达时间
17. 音频容量计算忘记除以 8（bit → Byte）
18. 关键路径 `ve` 取最小、`vl` 取最大（恰好反了）

**规范类**

19. 关系模式不标 PK/FK
20. SQL 用 `= NULL` 而不是 `IS NULL`

## 六、易混概念速查表

| A | B | 区分要点 |
| --- | --- | --- |
| 编译 | 解释 | 整体翻译 vs 逐句翻译 |
| 静态类型 | 动态类型 | 编译期检查 vs 运行期检查 |
| 重载 | 重写 | 同类不同参（编译期）vs 子类覆盖（运行期） |
| 策略 | 状态 | 客户端选算法 vs 内部状态驱动 |
| 装饰 | 代理 | 加职责 vs 控访问 |
| 适配器 | 桥接 | 事后补救 vs 事前设计 |
| 白盒 | 黑盒 | 看内部逻辑 vs 看输入输出 |
| 判定覆盖 | 条件覆盖 | 判定整体真假 vs 单个条件取值 |
| 驱动模块 | 桩模块 | 模拟上层调用 vs 模拟下层被调 |
| 逻辑独立性 | 物理独立性 | 外模式/模式 vs 模式/内模式 |
| 2NF | 3NF | 消除部分依赖 vs 消除传递依赖 |
| READ COMMITTED | REPEATABLE READ | 避免脏读 vs 避免不可重复读 |

## 七、考前一周清单

**学习上**

- [ ] 只看错题本 + 必看清单，不做新题、不碰偏题
- [ ] 每天 1 套"30 题轻量卷"保持手感（约 30 分钟）
- [ ] 公式卡过 3 遍：补码、流水线、Cache、页面置换、McCabe、子网、容量、关键路径
- [ ] 数字表过 3 遍：著作权 50 年、发明 20 年、实用新型 10 年、外观 15 年、商标 10 年
- [ ] 下午题模板各默写 1 遍（DFD 四步、数据库三问、算法四步）

**事务上**

- [ ] 打印准考证（多备 1 份），核对考点地址与考试时间
- [ ] 身份证在有效期内
- [ ] 提前 1 天踩点，估算通勤时间，预留 30 分钟缓冲
- [ ] 准备好黑色签字笔、铅笔（考场一般提供草稿纸）

**状态上**

- [ ] 提前 3 天把作息调到"上午 8:30 最清醒"
- [ ] 考前一晚不熬夜，睡眠比多背 10 个知识点更重要
- [ ] 进考场前只翻"必看清单"第一页，不翻新内容

## 八、考场心态

1. **第一题不会很正常**，标记跳过，不要影响后面 74 题。
2. **上午卷目标不是满分**，允许错 15 题；错 20 题也还在合格线附近。
3. **下午卷先写会的小问**，每道题的第 (1) 问通常最简单，先把分拿到手。
4. **不要和某道题较劲**，一道 15 分的题最多花 25 分钟。
5. **交卷前一定检查答题卡**，漏答一题就是 1 分，可能决定过不过。

> 最后一句：软考是"及格赛"不是"选拔赛"。把该拿的分拿稳，比追求难题更重要。
