## 六、口径与复现

| 项 | 口径 |
| --- | --- |
| 已作答题目 | `answers` 键数，一题多轮计 1 题 |
| 作答次数 | 每题 `right + wrong` 累加 |
| 正确率 | 累计 `right / 作答次数`；「本周」为相邻两快照作差，非单周独立样本 |
| 新增错题 | `wrong` 新增题号数；复错为已有题号 `count` 增长；按题去重、按次数计错 |
| 待攻克 | `wrong[*].resolved === false` 的条数 |
| 完成任务 | `tasks` 键数；小时按 `data-plan.js` 该任务 `hours` 汇总 |
| 计划投入 | 已打卡任务的**计划小时**，非实测用时（与「学习计划 → 累计投入」同源） |
| 测评 / 模考 | `exams` 长度；W1、W2 快照为 0，W3 起 3 次（阶段一 40/40、39/40、40/40） |

**已知局限**

- 备份只存累计次数与最后作答时间，无逐次时间戳 → 「本周」只能相邻两导出作差，无法按天拆，也分不开首轮与回炉正确率。
- 打卡只有 `{任务id: true}` 无完成时间 → 任务按计划周归属，超前完成的记在所属周次（如 W4 ~ W8 实际在 W2 内完成，W9、W10 在 W3 内完成）。

**复算**：读相邻两份 JSON，`answers` 逐题作差（题量取键差集、次数与正确数取差值），`wrong` 取题号与 `count` 差异，`tasks` 取键差集，按 `data-plan.js` 的 `hours` 汇总。
