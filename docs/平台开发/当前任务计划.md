> 已确认口径：①一条记录＝一次完成的练习（整卷 / 自选）；②入口并入 `#/stats`，真题首页加跳转按钮，不改 `index.html`；③掌握度按 13 模块（与 `RK.mastery()` 同粒度）；④导出复用「数据管理」，不新增独立导出。

### 5.1 数据来源与统计维度

1. **主来源 · 真题成绩记录（新建 `rk_sd_real_scores`，数组）**：每次练习完成时落盘一条，字段如下（最终键名以实施时源码为准）：

   | 字段 | 含义 |
   | --- | --- |
   | `id` | 唯一 id，`RS-<ts>-<序号>` |
   | `ts` | 完成时间（毫秒时间戳） |
   | `mode` | `paper`（整卷） / `custom`（自选） |
   | `paperKey` | 整卷时的套卷 key；自选为 `null` |
   | `filter` | 自选条件快照 `{ years, paperTypes, modules, n }` |
   | `total` | 本次练习题目数 |
   | `answered` | 实际作答数（未作答不计入得分率分母） |
   | `correct` | 答对数 |
   | `rate` | 得分率 `correct / answered`（0~1） |
   | `score` | 折算 75 题制得分 `round(rate × 75)`，与现有模考趋势同口径 |
   | `byModule` | `[{ key, total, correct, rate }]` 模块拆分 |

   > 为什么不直接用 `rk_sd_exams`：那是阶段测评 / 模拟考成绩，与真题练习分开统计，两套趋势并列但不混算。真题练习会话目前只在内存（`EX.createSession`），小结不落盘，因此必须新增记录。

2. **辅助来源**：`rk_sd_real_answers`（逐题累计 `right/wrong/last/ts`，算模块累计正确率）、`rk_sd_real_wrong`（`cause` / `stage`，算错因分布与未掌握错题数）。两者只读，不改字段、不改写入逻辑。

3. **明确不采信**：`rk_sd_answers`（自编作答，只用于现有模块掌握度对照）、`rk_sd_exams`（模考 / 阶段测评）；趋势图与记录表均分为「真题」「测评 / 模考」两组，不合并。

4. **统计维度（4 项）**：

   - **总分**：每次练习的卷面分（答对题数）＋折算 75 分制得分；列表同时显示 `correct/total` 与折算分，避免不同题量直接比大小。
   - **得分率**：`correct / answered`；按单次、按模块、按年份 / 卷型三个切法。
   - **知识点掌握度**：13 模块累计真题正确率（分母 `Σ(real_answers.right + wrong)`，未练模块记 0 落在圆心，与现有雷达同约定）；与自编掌握度雷达并列对照，不混算。
   - **历次趋势对比**：按 `ts` 升序的折算分序列；与「测评 / 模考」趋势同屏对照，但两条线分开呈现。

### 5.3 成绩记录管理

1. **存储**：新键 `rk_sd_real_scores`（数组，最新在前）；同时登记 `core.js` 的 `KEYS` 与 `clearAll`。旧数据无该键时按空数组处理，不影响既有备份导入。
2. **生成时机**：真题练习完成（现有 `finish` 置 `done = true` 处）时，按 `session.picked` 与题目答案计算 `correct / answered / rate / byModule` 并追加一条；中途退出不生成；未作答不进分母。
3. **查看**：`#/stats` 新增「真题成绩」分区，含 KPI（累计练习次数、平均得分率、最近一次折算分、最高折算分）＋记录表（日期 / 模式 / 年份卷型 / 题量 / 答对 / 得分率 / 折算分）。表格与现有「成绩记录表」并列，不混行。
4. **筛选**：按年份、卷型、模块、练习模式、时间范围（近 7 天 / 30 天 / 全部）五类条件；筛选同时作用于记录表、趋势图与分布图；筛选状态只在内存，不落盘（与 `rk_sd_real_sel` 的筛选记忆无关）。
5. **导出 / 导入**：**不新增导出入口**——在 `views-review.js` 的 `BACKUP_CATEGORIES` 增加 `realScores` 类别（`read()` 从 `rk_sd_real_scores` 读，`write()` 按类别覆盖），复用现有「数据管理」的导出 / 导入 / 确认弹窗；`_meta.categories` 未包含该类别时导入保持本机不变，v1 旧备份仍兼容（缺此类即跳过）；`progress/README.md` 字段表随备份结构补一行说明。

### 5.4 个性化学习建议

1. **生成规则（纯前端实时计算，不落盘）**：

   - **薄弱知识点**：模块真题累计正确率 `< 0.60`，且该模块累计作答 `≥ 3` 题（小样本不判定）；按正确率升序取前 3。每条给出模块名、正确率、样本题量、该模块 `rk_sd_real_wrong` 中 Top1 错因（复用 `RK.CAUSES` 中文名）。
   - **复习优先级**：优先分 `= weight × (1 − rate) + 0.5 × 未掌握错题数`（`weight` 取 `RK.MODULES` 权重；未掌握＝`rk_sd_real_wrong` 中 `stage !== 'done'` 按模块计数，上限 5）；降序取前 3 标「优先复习」，其余薄弱模块标「其次」。规则是启发式，实施后按实际分布微调，不写入备份。
   - **提升目标**：下次折算分目标＝`min(最近一次折算分 + 3, 当前阶段目标分)`；若最近一次 `< 45`（未达合格线）改为 `+5`，优先保及格；模块目标＝`min(rate + 0.10, 0.80)`。阶段目标分取 `data-plan.js` 既定 58 / 62 / 66 / 70，不新增配置。

2. **展示方式**：`#/stats` 真题分区顶部一张「复习建议」卡，三段式：①薄弱知识点列表（模块 / 正确率 / 样本量 / 主错因）；②优先级 Top3 徽标（高 / 中 / 低按排序）；③下次提升目标 KPI（总分目标＋模块目标）。每条薄弱模块附两个跳转：到真题模块按该模块筛选练习、到错题本看该题错因。无记录或样本不足时显示空态引导，不编造建议。

3. **不混算**：建议只读真题数据（`real_scores` / `real_answers` / `real_wrong`），不引用自编作答与模考成绩；文案标「基于真题练习」，避免被误读为全库掌握度。
