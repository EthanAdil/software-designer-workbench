### 5.4 数据模型、接口定义与交互流程

**数据模型（存储前缀 `rk_sd_`）**

| 类别 | 键 | 结构 |
| --- | --- | --- |
| 自编 | `answers` / `wrong` / `exams` / `tasks` | 题号→`{right,wrong,last,ts}`；题号→`{count,choice,choiceText,order,resolved,cause,conclusion,ts}`；成绩数组；任务 id→true |
| 真题 | `real_answers` / `real_wrong` / `real_sel` | 同上作答结构；错题增加 `stage/cause/conclusion/reviewTs`；筛选 `{y,t,m,n}` |
| 练习 | `practice_sel` | `{c,n}`：模块 key 数组 + 题量档 |
| 备份 v2 | `_meta` + 8 类根字段 | `_meta={format:'ruankao-sd-backup',version:2,mode,categories,schema}`；v1 无 `_meta`，按四类兼容 |

**题目与要点结构**：自编 `{id,module,topic,difficulty,points,stem,options,answer,explanation,tags}`；真题 `{id,paper,no,year,paperType,kind,module,topic,stem,options,answer,explanation,group,blank,source,answerSource,verified}`；要点块 `{title,items[]}`，跨模块唯一键为 `模块key|要点标题`。

**主要接口**：`RK.store.get/set/del`；`RK.record.*`、`RK.realRecord.*`（含 `setNote`/`stats`/`unresolvedIds`）；`RK.real.registerPaper/register/filterQuestions/registerExplanations/explanationFor`；`RK.registerQuestions/registerAfternoon`；`RK.modal/toast`；hash 路由 `#/dashboard|plan|knowledge|docs|practice|real|assessment|exam|review|stats`。

**主流程**：① 计划打卡 → 知识模块 → 刷题/真题 → 测评/模考 → 成绩分析 → 周复盘；② 真题练习 → 三段解析 → 真题错题（归因/三态）→ 重做待复习 → 备份导出；③ 备份导入 → 结构校验 → 确认弹窗 → 覆盖/回滚。

**建议**：在平台开发文档补一张「接口契约表」（函数、入参、出参、副作用、失败行为），避免后续扩展时误改统计口径；`points` 键格式写进约定，禁止新增要点时不带模块前缀。

### 5.5 代码结构与性能

现状：`core.js` 集中存储/路由/组卷/统计，`data-*.js` 数据层，`views-*.js` 视图层，`bank/`、`real/` 分目录，`tools/` 做静态校验；无构建步骤、无运行时依赖。531 + 202 题规模下浏览器端一次性脚本加载与全量 HTML 字符串渲染无明显瓶颈；vm sandbox 仅校验脚本使用，不进入运行时。

建议（均为低风险，不立即执行）：① 保持现有目录分层，新增题目/要点按既有文件追加，不新建构建工具；② `index.html` 脚本版本号按现有 `?v=` 机制递增，避免缓存旧数据；③ 题库超过约 2000 题再评估分片加载，当前不做；④ 明确不引入 npm/打包器，与零依赖目标冲突。

### 5.6 错误处理、输入校验与异常场景

| 已有机制 | 位置 |
| --- | --- |
| `localStorage` 探测、读写 try/catch、内存降级 | `assets/js/core.js:87-118` |
| 导出三步反馈、忙态防重、异常兜底与按钮复位 | `assets/js/views-review.js:371-412` |
| 导入 JSON 解析 / 根节点 / `_meta` / format / version / categories / 字段类型校验，确认后覆盖、失败回滚 | `assets/js/views-review.js:417-490` |
| 套卷与题目注册去重、字段继承、题干占位清理 | `assets/js/data-real.js:50-90` |
| 校验脚本对题量、答案越界、要点覆盖、解析三段、视图渲染做静态检查 | `tools/check-*.js` |

| 缺口 | 建议 |
| --- | --- |
| 导入只校验类别类型，不校验字段内部合法性 | 补 `stage ∈ todo/doing/done`、`answer` 为 0~3、`count/right/wrong` 非负整数、题号存在于题库 |
| 存储失败静默降级 | 写入失败时给一次明确 toast，避免用户误以为已保存 |
| 备份体积无上限提示 | 文件超过约 1MB 时建议「选择性导出」并列出类别条数 |
| 无题可取/筛选无匹配的边界提示 | 复核各视图空态文案，统一为「匹配 0 题，请调整筛选」 |
