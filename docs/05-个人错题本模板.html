05 · 个人错题本模板

站内「错题本」已支持逐题选择错因、填写一句话结论，并随 CSV 一起导出；这份模板用于打印、手写或离线归档，字段与站内保持一致。

一、填写规则

  1. 当天填：做题当天归档，隔天只剩"好像错过"的印象。
  2. 一题一行：只写题干关键词，不抄整题；抄题干的时间够再做 3 道题。
  3. 错因必须选标签（见第三节），不写"粗心""没看清"。
  4. 一句话结论要能执行：写"看到 X 就先做 Y"，不写"下次注意"。
  5. 两次答对才移出：错题重做一次答对，可能只是记住了答案。

二、选择题速记表（上午卷）

按周分节；字母以你作答那次的选项顺序为准（站内选项每次会重排）。

三、错因标签（每题只选一个主因）

标签判定标准一句话结论该怎么写
概念混淆两个概念都见过，但分不清边界写出区分点："A 是……，B 是……，判断看……"
公式记错公式本身记错、少项、分子分母颠倒写出正确公式 + 一个代入自检
计算失误公式对，算错、进位错或单位错写出易错步骤："先换单位，再乘"
审题偏差看漏"不正确""最多""至少"等限定写出圈词动作："先圈否定词再选"
知识盲区完全没学过或想不起写出补法："回看 X 文档第 N 节 + 做 5 题"
术语不熟中文术语与英文/缩写对不上写出术语对："命中率 = hit rate"
时间不够会做但没时间做到写出取舍："超过 90 秒先标记跳过"
蒙对未掌握选对了，但过程是猜的按错题处理，结论标"待验证"

CS-0018 位补码的表示范围B（-127 ~ +127）A（-128 ~ +127）公式记错补码负端比正端多一个 -2(n-1)：先写 -2(n-1) ~ 2(n-1)-1，再代入 n=8

案例示例（算法填空）

  • 来源 / 题号：下午卷 · 算法设计 · 0-1 背包
  • 模块：数据结构与算法
  • 题型：代码填空

题目：补全 dp[j] = max(dp[j], dp[j-w[i]] + v[i]) 的循环方向与边界。

我的答案：for (j = w[i]; j <= C; j++)（正序）

正确答案 / 评分点：for (j = C; j >= w[i]; j--)（逆序）；漏了"逆序保证每件物品只选一次"这个评分点。

错因：概念混淆（0-1 背包与完全背包的状态更新方向）。

一句话结论：一维背包先看"物品能不能重复选"——不能重复就逆序，能重复就正序。
