# 05 · 个人错题本模板

> 站内「错题本」已支持逐题选择错因、填写一句话结论，并随 CSV 一起导出；这份模板用于打印、手写或离线归档，字段与站内保持一致。

## 一、填写规则

1. **当天填**：做题当天归档，隔天只剩"好像错过"的印象。
2. **一题一行**：只写题干关键词，不抄整题；抄题干的时间够再做 3 道题。
3. **错因必须选标签**（见第三节），不写"粗心""没看清"。
4. **一句话结论要能执行**：写"看到 X 就先做 Y"，不写"下次注意"。
5. **两次答对才移出**：错题重做一次答对，可能只是记住了答案。

## 三、错因标签（每题只选一个主因）

| 标签 | 判定标准 | 一句话结论该怎么写 |
| --- | --- | --- |
| 概念混淆 | 两个概念都见过，但分不清边界 | 写出区分点："A 是……，B 是……，判断看……" |
| 公式记错 | 公式本身记错、少项、分子分母颠倒 | 写出正确公式 + 一个代入自检 |
| 计算失误 | 公式对，算错、进位错或单位错 | 写出易错步骤："先换单位，再乘" |
| 审题偏差 | 看漏"不正确""最多""至少"等限定 | 写出圈词动作："先圈否定词再选" |
| 知识盲区 | 完全没学过或想不起 | 写出补法："回看 X 文档第 N 节 + 做 5 题" |
| 术语不熟 | 中文术语与英文/缩写对不上 | 写出术语对："命中率 = hit rate" |
| 时间不够 | 会做但没时间做到 | 写出取舍："超过 90 秒先标记跳过" |
| 蒙对未掌握 | 选对了，但过程是猜的 | 按错题处理，结论标"待验证" |

### 选择题示例

| 题号 | 题目（关键词） | 我的答案 | 正确答案 | 错因 | 一句话结论 |
| --- | --- | --- | --- | --- | --- |

### 案例示例（算法填空）

- 来源 / 题号：下午卷 · 算法设计 · 0-1 背包
- 模块：数据结构与算法
- 题型：代码填空

**题目**：补全 `dp[j] = max(dp[j], dp[j-w[i]] + v[i])` 的循环方向与边界。

**我的答案**：`for (j = w[i]; j <= C; j++)`（正序）

**正确答案 / 评分点**：`for (j = C; j >= w[i]; j--)`（逆序）；漏了"逆序保证每件物品只选一次"这个评分点。

**错因**：概念混淆（0-1 背包与完全背包的状态更新方向）。

**一句话结论**：一维背包先看"物品能不能重复选"——不能重复就逆序，能重复就正序。

> 每周日从本周错题里抽四类计数（概念 / 公式 / 计算 / 审题），再写 2~3 条共同点。归类以「错在哪一步」为准，不完全照抄站内的错因标签（标签是当天印象，这里是复核后的结论）。

### W1（2026-11-02 ~ 11-08）· 计算机组成与体系结构 · 35 题错 4

| 题号 | 考点 | 我的答案 | 正确答案 | 归类 | 错在哪一步 |
| --- | --- | --- | --- | --- | --- |
| CS-002 | 8 位补码 `10000000` 的真值 | 未还原（当日记录未存选项顺序） | -128 | 公式（端值） | 只记住「符号位为 1 是负数」，没记住补码负端比正端多一个 `-2^(n-1)` |
| CS-011 | Cache 平均访问时间（2ns / 20ns / 命中率 95%） | 2.9 ns | 3.0 ns | 公式（漏项） | 未命中路径只算了主存 20ns，漏掉先查 Cache 的 2ns |
| CS-032 | 2 个部件并联，各 0.9，系统可靠度 | 0.9 | 0.99 | 公式（漏指数） | 写成 `1-(1-0.9)`，漏了 n 次方；0.9 这个值只可能由漏掉指数得到 |
| CS-022 | 指令流水线的正确说法 | D：流水线能缩短单条指令执行时间 | B：加速比上限 = 流水段数 k | 概念 | 把「吞吐率提高」当成「单条指令变快」；没记住 `S = nk/(k+n-1)`，n→∞ 才趋于 k |

> 复核：CS-032 原标「计算失误」，实为公式漏指数——0.9 不是小数点精度问题，是 `1-(1-R)^n` 的 n 丢了；CS-002 原标「知识盲区」，实为端值没背（`10000000` 对应 -128 是死记项，靠推导容易绕回自身）。

### W1 共同点

1. **没有一道是算错或看错题**：计算 0、审题 0。四则运算和读题不是短板，短板在公式本身的记忆完整性。
2. **三道公式题的错误动作同构**：都漏一个要素——CS-011 漏一项时间、CS-032 漏一个指数、CS-002 漏一个端值。共同动作是默写公式只写主体，没写「适用条件 / 项数 / 端值」。
3. **全栽在极端取值上**：最小值（补码 `-2^(n-1)`）、n=2（并联）、n→∞（加速比上限）。平时只背一般形式，没背过 n=1 / n=2 / n→∞ 的退化样子。
4. **限定词没触发换公式**：「并联」「未命中」「上限」「最小」出现时仍按直觉套（串联式相乘、只算主存、用通用加速比）。这和审题偏差不同——题问什么都看清了，缺的是「限定词 → 换公式」的条件反射。
5. **集中在同一模块的 4 个不同小节**：数据表示 / Cache / 可靠性 / 流水线。不是某一节没读，而是跨节的同类习惯问题；35 题错 4（约 88.6%）也说明「学过」和「记死」之间还差一层。
