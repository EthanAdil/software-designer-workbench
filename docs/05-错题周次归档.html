3. 相关知识点归纳

  • 文件索引：一级索引最大 = (块大小 ÷ 索引项) × 块大小；1KB/4B = 256 → 256KB；二级 = 256 × 256KB = 64MB。

  • ISO 9126 六特性：功能、可靠、易用、效率、可维护、可移植。

3. 相关知识点归纳

  • 排序：建堆 O(n)（自底向上），堆排序整体 O(n log n)；简单选择排序比较次数恒为 n(n−1)/2，移动次数 0 ~ 3(n−1)。
  • 最短路径：Dijkstra 单源 O(n²)；Floyd 全源 O(n³)、空间 O(n²)，可带负权边（不能有负权回路）。
  • 二叉排序树：ASL 取决于插入顺序；递增插入退化为单支，n=5 时 ASL=(1+2+3+4+5)/5=3；平衡才有 O(log n)。
  • 完全二叉树：n0 = n2 + 1；n 偶时 n0 = n/2，n 奇时 n0 = (n+1)/2；100 个结点 → 50 个叶子。
  • m 阶 B 树：非根非叶结点关键字 ⌈m/2⌉−1 ~ m−1；5 阶即 2 ~ 4，根至少 1 个。
  • 线性表：顺序表插入平均移动 n/2，删除 (n−1)/2；链表插入不移动元素。
  • 编译：目标代码生成与硬件关系最密切；编译 vs 解释 = 是否生成目标代码。
  • 前缀表达式：a+b*(c−d) → + a * b - c d，方法「括号 → 高优先级 → 低优先级」逐层前置。

  • 站内标签把 5 次记成「计算失误」：其中 CS-032 实为并联可靠度公式漏指数（0.9 只可能由丢了 n 次方得到），CS-002 标「知识盲区」实为端值没背。
  • 三道公式题错误动作同构：都漏一个要素（CS-011 漏一项时间、CS-032 漏一个指数、CS-002 漏一个端值）——默写公式只写主体，没写适用条件、项数与端值。
  • 全栽在极端取值：补码最小值、并联 n=2、加速比 n→∞；平时只背一般形式，没背过退化样子。
  • 限定词没触发换公式：「并联 / 串联、未命中、上限、最小」出现时仍按直觉套，缺「限定词 → 换公式」的条件反射。

3. 相关知识点归纳

  • 补码（8 位）：-2(n-1) ~ 2(n-1)-1，即 -128 ~ +127；10000000 是 -128，无对应正数。
  • Cache 平均访问时间 = 命中率 × t_Cache + 未命中率 × (t_Cache + t_主存)；95% × 2 + 5% × 22 = 3.0 ns。
  • 寻址空间 = 2^地址线根数 × 数据线宽度；20 根地址线 + 8 位数据线 = 220 B = 1MB。
  • 并联可靠度 = 1-(1-R₁)(1-R₂)…；n 个同可靠度部件 = 1-(1-R)n；两部件 0.9 → 0.99。
  • 流水线加速比 S = nk/(k+n-1)，n→∞ 时上限为 k；吞吐率提高 ≠ 单条指令变快。
  • 执行时间 = 指令数 × CPI ÷ 主频：107 × 2 ÷ 2GHz = 10 ms；100 万 × 2 ÷ 1GHz = 2 ms。
  • CPU：PC 存下一条指令地址，取指后指令先入 IR 再译码。

4. 改进措施

  • 四张公式卡（补码范围、平均访问时间、并联可靠度、流水线加速比），按「公式 / 适用条件 / n=1 时 / n=2 或极端时 / 我上次错在哪」写满。
  • 改错因：CS-032 错因改「公式记错」、结论改公式本身；CS-002 结论改「10000000 = -128」。
  • 二刷待攻克：CS-046、CS-039（11-06 状态），以连续两次答对且能复述判据为自查标准；系统标记仍按最近一次答对自动更新。
  • 立条件反射清单：见「并联 / 串联、未命中、上限、最小 / 最大、段数」先默写公式再代数字。
  • 验收：W1 错题二刷连续两次全对；W2 新错题中「公式漏项」≤ 1 道。

六、错因标签与复核口径

标签判定标准一句话结论怎么写
概念混淆两个概念都见过，但分不清边界写出区分点：A 是……，B 是……，判断看……
公式记错公式本身记错、少项、分子分母颠倒写出正确公式 + 一个代入自检
计算失误公式对，算错、进位错或单位错写出易错步骤：先换单位，再乘
审题偏差看漏「不正确」「最多」「至少」等限定写出圈词动作：先圈否定词再选
知识盲区完全没学过或想不起写出补法：回看 X 文档第 N 节 + 做 5 题
术语不熟中文术语与英文 / 缩写对不上写出术语对：命中率 = hit rate
时间不够会做但没时间做到写出取舍：超过 90 秒先标记跳过
蒙对未掌握选对了，但过程是猜的按错题处理，结论标「待验证」
