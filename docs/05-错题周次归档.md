- 完全二叉树：n0 = n2 + 1；n 偶时 n0 = n/2，n 奇时 n0 = (n+1)/2；100 个结点 → 50 个叶子。
- m 阶 B 树：非根非叶结点关键字 ⌈m/2⌉−1 ~ m−1；5 阶即 2 ~ 4，根至少 1 个。
- 线性表：顺序表插入平均移动 n/2，删除 (n−1)/2；链表插入不移动元素。
- 编译：目标代码生成与硬件关系最密切；编译 vs 解释 = 是否生成目标代码。
- 前缀表达式：a+b*(c−d) → + a * b - c d，方法「括号 → 高优先级 → 低优先级」逐层前置。

**3. 相关知识点归纳**

## 五、错因标签与复核口径

| 标签 | 判定标准 | 一句话结论怎么写 |
| --- | --- | --- |
| 概念混淆 | 两个概念都见过，但分不清边界 | 写出区分点：A 是……，B 是……，判断看…… |
| 公式记错 | 公式本身记错、少项、分子分母颠倒 | 写出正确公式 + 一个代入自检 |
| 计算失误 | 公式对，算错、进位错或单位错 | 写出易错步骤：先换单位，再乘 |
| 审题偏差 | 看漏「不正确」「最多」「至少」等限定 | 写出圈词动作：先圈否定词再选 |
| 知识盲区 | 完全没学过或想不起 | 写出补法：回看 X 文档第 N 节 + 做 5 题 |
| 术语不熟 | 中文术语与英文 / 缩写对不上 | 写出术语对：命中率 = hit rate |
| 时间不够 | 会做但没时间做到 | 写出取舍：超过 90 秒先标记跳过 |
| 蒙对未掌握 | 选对了，但过程是猜的 | 按错题处理，结论标「待验证」 |

站内标签是当天印象，归档时按「错在哪一步」复核；两者不一致就写「站内 → 复核」，以复核结果计数。
