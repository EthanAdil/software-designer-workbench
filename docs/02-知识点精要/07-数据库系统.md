# 07 · 数据库系统（上午 7 题 + 下午 1 题）

## 一、三级模式与两级映像

| 模式 | 别名 | 描述 | 数量 |
| --- | --- | --- | --- |
| 外模式 | 子模式 / 用户模式 | 用户看到的数据视图 | 多个 |
| 模式 | 概念模式 / 逻辑模式 | 全体数据的逻辑结构 | 一个 |
| 内模式 | 存储模式 | 物理存储结构 | 一个 |

| 映像 | 保证 |
| --- | --- |
| 外模式/模式 | **逻辑独立性**（逻辑结构变，用户视图不变） |
| 模式/内模式 | **物理独立性**（存储变，逻辑结构不变） |

## 二、ER 模型转换

| 联系类型 | 转换方式 |
| --- | --- |
| 1:1 | 可合并到任一端，把另一端主键作为外键 |
| 1:n | 把 1 端主键放入 n 端作外键 |
| m:n | **必须独立建表**，主键为两端主键的组合，可携带联系属性 |

- 多值属性：单独成表
- 弱实体：依赖强实体的主键
- ER 图合并冲突：属性冲突、命名冲突、结构冲突

## 三、关系代数

| 运算 | 符号 | 含义 | SQL 对应 |
| --- | --- | --- | --- |
| 选择 | σ | 按条件取行 | WHERE |
| 投影 | π | 取列并去重 | SELECT |
| 连接 | ⋈ | 按条件合并两表 | JOIN |
| 笛卡儿积 | × | 全组合 | CROSS JOIN |
| 并/差/交 | ∪ / − / ∩ | 集合运算 | UNION / EXCEPT / INTERSECT |
| 除 | ÷ | "对所有…"语义 | NOT EXISTS 嵌套 |

## 四、规范化

| 范式 | 要求 | 消除的问题 |
| --- | --- | --- |
| 1NF | 属性不可再分 | 非原子属性 |
| 2NF | 1NF + 消除非主属性对码的**部分**依赖 | 部分依赖 |
| 3NF | 2NF + 消除非主属性对码的**传递**依赖 | 传递依赖 |
| BCNF | 所有非平凡函数依赖的决定因素都是候选键 | 主属性对码的依赖 |

**候选键求解（闭包法）**：从每个属性/属性组出发求闭包，若闭包包含全部属性且无冗余，则为候选键。

**无损连接分解判定**：`R1 ∩ R2 → R1 - R2` 或 `R1 ∩ R2 → R2 - R1` 成立。

## 五、SQL 要点

```sql
-- 执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
SELECT 列, 聚合函数
FROM 表 [JOIN 表 ON 条件]
WHERE 行条件
GROUP BY 分组列
HAVING 分组后条件
ORDER BY 排序列 [ASC|DESC];
```

| 类别 | 语句 |
| --- | --- |
| DDL | CREATE / ALTER / DROP |
| DML | SELECT / INSERT / UPDATE / DELETE |
| DCL | GRANT / REVOKE |
| 事务 | COMMIT / ROLLBACK / SAVEPOINT |

**经典写法**

```sql
-- 每门课平均分 > 80
SELECT 课程号, AVG(成绩) FROM 选课 GROUP BY 课程号 HAVING AVG(成绩) > 80;

-- 没被选修的课程
SELECT * FROM 课程 WHERE 课程号 NOT IN (SELECT 课程号 FROM 选课);

-- 尚未归还
SELECT * FROM 借阅 WHERE 归还日期 IS NULL;

-- 前 3 名
SELECT 工号, SUM(工时) AS 总工时 FROM 参与 GROUP BY 工号 ORDER BY 总工时 DESC LIMIT 3;
```

## 六、事务与并发

**ACID**：原子性、一致性、隔离性、持久性。

| 隔离级别 | 脏读 | 不可重复读 | 幻读 |
| --- | --- | --- | --- |
| READ UNCOMMITTED | 可能 | 可能 | 可能 |
| READ COMMITTED | 不会 | 可能 | 可能 |
| REPEATABLE READ | 不会 | 不会 | 可能 |
| SERIALIZABLE | 不会 | 不会 | 不会 |

**封锁**：共享锁 S（读）、排他锁 X（写）。
**两段锁协议**：扩展阶段只加锁、收缩阶段只解锁；遵守 2PL 的调度一定可串行化，但可能死锁。
**死锁预防**：一次封锁法、顺序封锁法。

**备份恢复**：静态/动态转储、海量/增量转储、日志（UNDO 撤销未提交、REDO 重做已提交）、检查点。

## 七、自检题

1. 逻辑独立性由哪个映像保证？
2. `R(A,B,C)`，`F={A→B, B→C}`，候选键是什么？
3. m:n 联系转关系模式时主键怎么定？
4. 哪种隔离级别能避免幻读？
5. 两段锁协议能保证什么，不能避免什么？

> 答案速查：1) 外模式/模式映像；2) A（A+=ABC）；3) 两端主键的组合；4) SERIALIZABLE；5) 保证可串行化，不能避免死锁。
