三、TCP 与 UDP

特性TCPUDP
连接面向连接无连接
可靠性可靠（确认、重传、排序）不可靠
开销首部 20 字节起首部 8 字节
适用文件传输、网页、邮件实时音视频、DNS、DHCP

三次握手：SYN → SYN+ACK → ACK
四次挥手：FIN → ACK → FIN → ACK，主动关闭方进入 TIME_WAIT 等待 2MSL（保证最后 ACK 可达 + 让旧报文消失）。

拥塞控制四阶段

阶段行为
慢开始cwnd 从 1 开始，每 RTT 翻倍（指数）
拥塞避免cwnd 每 RTT 加 1（线性），达到 ssthresh 后进入
快重传收到 3 个重复 ACK 立即重传丢失段，不等超时
快恢复ssthresh 与 cwnd 减半，直接进入拥塞避免

五、路由与其他

协议类型算法特点
RIP内部网关距离向量跳数度量，最大 15 跳
OSPF内部网关链路状态（Dijkstra）收敛快，支持区域划分

编码：曼彻斯特（自同步，效率 50%）、差分曼彻斯特、NRZ、4B/5B。
复用：FDM（频分）、TDM（时分）、WDM（波分）、CDM（码分）。

六、自检题

  1. /26 掩码是什么？每个子网可用主机数？
  2. 交换机能否隔离广播域？
  3. TCP 三次握手的第二次标志位是什么？
  4. RIP 用什么算法？最大跳数？
  5. 192.168.4.0/24 与 192.168.5.0/24 能否聚合为 /23？

答案速查：1) 255.255.255.192，62 台；2) 不能，需 VLAN 或路由器；3) SYN=1, ACK=1；4) 距离向量，15 跳；5) 不能，第三字节 00000100 与 00000101 前 7 位不同，需 /22 才覆盖。
