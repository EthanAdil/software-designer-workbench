一、多媒体计算三公式

音频数据量(字节) = 采样频率 × 量化位数 × 声道数 × 时间(秒) / 8
图像数据量(字节) = 水平像素 × 垂直像素 × 颜色深度 / 8
视频数据量(字节) = 帧率 × 每帧数据量 × 时间(秒)

例题

题目计算结果
44.1kHz、16 位、双声道、1 分钟44100×16×2×60/8≈ 10.1 MB
1024×768、24 位真彩色、未压缩1024×768×24/8≈ 2.25 MB
25fps、每帧 1MB、10 秒25×1MB×10250 MB

采样定理：采样频率 ≥ 2 倍信号最高频率。人耳 20Hz~20kHz，故 CD 用 44.1kHz。

二、格式特性

格式类型有损/无损透明动画适用
BMP位图无损不支持否原始位图存储
JPG位图有损不支持否照片
GIF位图无损支持（1 位）支持图标、简单动图（256 色）
PNG位图无损支持（alpha）否网页图形、截图
SVG矢量无损支持支持（SMIL）图标、图表
WAV音频无损——原始音频
MP3音频有损——音乐分发
MIDI音频———演奏指令，非波形，不含人声

三、压缩与冗余

冗余类型含义利用方式
空间冗余相邻像素相似JPEG 的 DCT
时间冗余相邻帧相似MPEG 运动补偿
视觉冗余人眼不敏感量化表、色度下采样
编码冗余码长分配不合理哈夫曼编码

无损：哈夫曼、游程 RLE、LZW、算术编码。
有损：JPEG（静态）、MPEG（运动）、MP3。
压缩比 = 压缩前 / 压缩后。

四、专业英语应试策略

题材分布：软件工程、数据库、网络、操作系统、AI/新技术，各 1 篇左右。

解题四步

  1. 先通读全文抓主题（30 秒），不要被生词卡住；
  2. 看空格前后判断词性与搭配（冠词/形容词后填名词，助动词后填动词原形/过去分词）；
  3. 抓逻辑连接词：however（转折）、therefore（因果）、in addition（递进）、whereas（对比）；
  4. 排除法 + 专业词优先（与主题强相关的术语正确率更高）。

常见干扰项特征

  • 词性正确但语义相反（如 improve / impair）
  • 与主题无关的同领域词（讲数据库却给 network）
  • 单复数或时态不符

五、自检题

  1. 采样频率 8kHz、8 位、单声道、30 秒的音频数据量是多少？
  2. 一幅 800×600 的 8 位灰度图未压缩占多少 KB？
  3. 为什么说 MIDI 不能用来录歌？
  4. 支持透明通道且无损的位图格式是？
  5. 专业英语中 however 提示什么逻辑关系？

答案速查：1) 8000×8×1×30/8 = 240,000 B ≈ 234 KB；2) 800×600×8/8 = 480,000 B ≈ 469 KB；3) MIDI 记录演奏指令（音高、力度、时长），不含波形采样，无法记录人声；4) PNG；5) 转折。
