10 · 多媒体（2 题）+ 专业英语（5 题）

多媒体是"公式 + 格式"的小模块，5 分钟能拿分；专业英语是 1 篇短文 5 空，靠术语积累与上下文逻辑，投入产出比最高。两块的共同点是：不需要深入推导，记住规则就能得分。

二、多媒体计算

2.1 三个公式

音频数据量(字节) = 采样频率 × 量化位数 × 声道数 × 时间(秒) / 8
图像数据量(字节) = 水平像素 × 垂直像素 × 颜色深度 / 8
视频数据量(字节) = 帧率 × 每帧数据量 × 时间(秒)

2.2 例题

题目计算结果
CD 音质立体声，44.1kHz、16 位、双声道、1 分钟44100×16×2×60/8≈ 10.1 MB
1024×768、24 位真彩色、未压缩1024×768×24/8≈ 2.25 MB
25fps、每帧 1MB、10 秒25×1×10250 MB
8kHz、8 位、单声道、30 秒8000×8×1×30/8240,000 B ≈ 234 KB

单位陷阱：题目选项常同时给 KB 与 MB、B 与 bit。先统一成字节再换算；1MB = 1024KB = 220 B，若题目按 1000 计，选项会体现差异。看到"约"字通常按 1024 估算。

2.3 采样定理

采样频率必须大于等于信号最高频率的 2 倍（奈奎斯特），否则会发生混叠。人耳听觉范围 20Hz~20kHz，所以 CD 采样率取 44.1kHz（略高于 40kHz，留余量）。

常见采样率：电话 8kHz、CD 44.1kHz、DVD 48kHz。

三、图像与视频

3.1 位图与矢量图

类型存储内容缩放体积适用
位图每个像素的颜色值放大会失真、出现锯齿大照片、复杂图像
矢量图图形指令（线条、曲线、填充）缩放不失真小图标、LOGO、工程图

3.2 分辨率与颜色深度

  • 显示分辨率：屏幕能显示的像素数（1920×1080）；
  • 图像分辨率：图像本身的像素数；
  • 打印分辨率：DPI（每英寸点数），影响打印清晰度。

颜色深度：8 位 = 256 色；16 位 = 65536 色；24 位 = 真彩色（约 1677 万色）；32 位 = 24 位颜色 + 8 位 Alpha 透明通道。

3.3 色彩空间

色彩空间用途特点
RGB显示器、屏幕加色模式，红绿蓝叠加
CMYK印刷减色模式，青品黄黑
YUV/YCbCr视频压缩亮度与色度分离，可利用人眼对亮度更敏感的特性压缩色度

3.4 视频

  • 帧率：PAL 25fps、NTSC 30fps、电影 24fps；
  • 扫描方式：逐行扫描（ progressive）画面稳定，隔行扫描（interlaced）带宽减半但可能有梳状伪影；
  • 流媒体：边下载边播放，适合网络传输，需缓冲与码率自适应；
  • 视频容量计算别忘了"每帧数据量"本身可能还要按图像公式算。

四、音频

  • 数字化三步：采样（时间离散）→ 量化（幅度离散）→ 编码（二进制表示）。
  • 量化位数越高，动态范围越大、信噪比越高；采样率越高，能还原的频率越高。
  • MIDI：记录音高、力度、时长、音色等演奏指令，文件极小，可编辑、可换音源；但它记录的是"怎么演奏"，不是声音波形，不能记录人声与自然声。
  • 波形音频：WAV（无损、体积大）、MP3（有损、心理声学模型）、AAC（效率高于 MP3）。

五、压缩

5.1 冗余类型

冗余类型含义利用方式
空间冗余相邻像素相似JPEG 的 DCT
时间冗余相邻帧相似MPEG 运动补偿
视觉冗余人眼对某些细节不敏感量化表、色度下采样
编码冗余码长分配不合理哈夫曼编码、算术编码

5.2 有损与无损

类型方法特点
无损哈夫曼、游程 RLE、LZW、算术编码可完全还原，压缩比有限
有损JPEG、MPEG、MP3压缩比高，不可完全还原

JPEG 流程：RGB → YCbCr → 8×8 分块 → DCT → 量化（有损的关键）→ 熵编码（哈夫曼/算术）。

MPEG 帧类型：

帧编码方式说明
I 帧帧内编码独立解码，作为随机访问点
P 帧前向预测参考前面的 I/P 帧
B 帧双向预测参考前后帧，压缩率最高

压缩比 = 压缩前大小 / 压缩后大小。

六、专业英语

6.1 题材分布

真题通常是一篇 200 词左右的短文，挖 5 个空，题材集中在：

  1. 软件工程（过程模型、需求、测试、维护）；
  2. 数据库（事务、索引、规范化、并发）；
  3. 网络（协议、路由、拥塞、安全）；
  4. 操作系统（进程、内存、调度、死锁）；
  5. 新技术（AI、云计算、大数据、区块链）。

6.2 解题四步

  1. 先通读全文抓主题（30 秒），不要被生词卡住；
  2. 看空格前后判断词性：冠词/形容词后填名词，助动词后填动词原形或过去分词，介词后填名词/动名词；
  3. 抓逻辑连接词：however（转折）、therefore（因果）、in addition（递进）、whereas（对比）、for example（举例）；
  4. 排除法 + 专业词优先：与主题强相关的术语正确率更高。

6.3 高频词表

6.4 常见干扰项

  • 词性正确但语义相反（improve / impair、increase / reduce）；
  • 与主题无关的同领域词（讲数据库却给 network）；
  • 单复数或时态不符；
  • 形近词（adapt / adopt、principal / principle）。

练习建议：每篇做完后把 5 个空的句子抄下来，遮住答案复述；错题标注是"词不认识"还是"逻辑没读出来"，前者补词汇、后者练连接词。

七、速记表

音频 = 采样率 × 位数 × 声道 × 时间 / 8
图像 = 宽 × 高 × 色深 / 8
视频 = 帧率 × 每帧大小 × 时间
采样率 ≥ 2 × 最高频率
8 位 256 色，24 位真彩色，32 位带 Alpha
PAL 25fps、NTSC 30fps、电影 24fps
MIDI 是演奏指令，不是波形
JPEG 有损（DCT + 量化）；MPEG 利用时间冗余
无损：哈夫曼、RLE、LZW；有损：JPEG、MPEG、MP3

九、自检题

  1. 采样频率 8kHz、8 位、单声道、30 秒的音频数据量是多少？（对应题库 MM-016）
  2. 一幅 800×600 的 8 位灰度图未压缩占多少 KB？（对应题库 MM-015）
  3. 为什么说 MIDI 不能用来录歌？（对应题库 MM-006）
  4. 支持透明通道且无损的位图格式是？（对应题库 MM-013）
  5. 专业英语中 however 提示什么逻辑关系？（对应题库 ENG-029）
  6. 24 位真彩色能表示多少种颜色？（对应题库 MM-002）
  7. JPEG 压缩中哪一步是有损的？（对应题库 MM-004）
  8. MPEG 的 I、P、B 帧分别如何编码？（对应题库 MM-010）
  9. 视频容量如何计算？（对应题库 MM-009）
  10. RGB 与 CMYK 分别用于什么场景？（对应题库 MM-007）

答案与解析：
1) 8000×8×1×30/8 = 240,000 B ≈ 234 KB。
2) 800×600×8/8 = 480,000 B ≈ 469 KB。
3) MIDI 记录演奏指令（音高、力度、时长），不含波形采样，无法记录人声。
4) PNG。
5) 转折。
6) 224 ≈ 1677 万种。
7) 量化（DCT 本身可逆，量化丢弃高频细节）。
8) I 帧帧内编码、P 帧前向预测、B 帧双向预测。
9) 帧率 × 每帧数据量 × 时间；每帧数据量按图像公式计算。
10) RGB 用于显示器等发光设备，CMYK 用于印刷。
