02 · 操作系统（上午 6 题）

一、进程与状态

三态：就绪 ⇄ 运行 → 阻塞 → 就绪
禁止：阻塞 → 运行（必须先回就绪）、就绪 → 阻塞
状态转换触发者原因
就绪 → 运行调度程序被选中
运行 → 就绪进程自身/系统时间片到、被抢占
运行 → 阻塞进程自身请求 I/O、申请资源失败、等待事件
阻塞 → 就绪系统等待的事件发生

二、PV 操作（必考）

P(S): S = S - 1;  if (S < 0) 阻塞当前进程
V(S): S = S + 1;  if (S <= 0) 唤醒一个等待进程

S > 0  : 还有 S 个可用资源
S = 0  : 资源刚好用完，无等待
S < 0  : |S| 个进程在等待

生产者-消费者（缓冲区容量 n）

信号量初值含义
mutex1互斥访问缓冲区
emptyn空闲槽位数
full0已放产品数
生产者：P(empty) → P(mutex) → 放产品 → V(mutex) → V(full)
消费者：P(full)  → P(mutex) → 取产品 → V(mutex) → V(empty)

顺序不可颠倒：先 P 资源信号量，再 P 互斥信号量。反过来会死锁。

三、存储管理

方式地址结构碎片特点
页式页号 + 页内地址内部碎片无外部碎片，需页表
段式段号 + 段内地址外部碎片便于共享与保护
段页式段号 + 页号 + 页内地址内部碎片两次查表，开销大

地址换算：页面大小 4KB = 0x1000，低 12 位为页内偏移。
例：逻辑地址 0x2A5F → 页号 2，偏移 0xA5F。

页面置换

算法特点
OPT理论最优，无法实现，作对比基准
FIFO实现简单，存在 Belady 异常
LRU最近最久未使用，性能接近 OPT，实现需硬件支持
LFU按访问频率淘汰

四、文件与设备

物理结构随机访问扩展碎片
连续支持困难有外部碎片
链接不支持（只能顺序）容易无
索引支持容易索引表占空间

位示图换算（字号、位号从 0 开始）

字号 = 物理块号 / 字长
位号 = 物理块号 % 字长
物理块号 = 字号 × 字长 + 位号

磁盘调度

算法策略缺点
FCFS按请求顺序移臂距离大
SSTF最近的先服务可能饥饿
SCAN单向扫到端点再折返边缘请求等待久
CSCAN到端点直接回起点回程不服务

五、调度与周转

周转时间 = 完成时间 - 到达时间
带权周转时间 = 周转时间 / 服务时间
平均周转时间 = Σ周转时间 / 作业数

调度算法：FCFS（公平）、SJF（平均等待最短，可能饥饿）、优先级、时间片轮转、多级反馈队列。

六、自检题

  1. 信号量初值 3，当前值 -1，说明什么？
  2. 优先级反转与死锁的区别？
  3. LRU 与 FIFO 在"增加物理块缺页反而增多"上分别表现如何？
  4. 页面大小 8KB，逻辑地址 0x3FFF 的页号与偏移？
  5. 4 个作业 FCFS，如何算平均带权周转时间？

答案速查：1) 3 个资源已全部分配，且还有 1 个进程在等待；2) 优先级反转是调度问题（低优先级持锁阻塞高优先级），死锁是循环等待；3) FIFO 有 Belady 异常，LRU 不会；4) 页号 1，偏移 0x1FFF；5) 先算完成时间→周转→除以服务时间。
