01 · 计算机组成与体系结构（上午 7 题）

对应知识模块要点：数据表示与运算；CPU 与体系结构；存储系统；总线、I/O 与可靠性；性能指标
范围：要点即出题范围（题库逐题标注 points）；要点之外的细节为加深内容，只求理解，不单独出题。

本模块公式固定、套路清晰：计算题集中在补码、浮点、校验码、流水线、Cache、可靠性、性能七处；概念题集中在 RISC/CISC、Flynn、总线、I/O 方式、寻址方式。目标是计算题一分不丢，概念题最多错一道。

二、数据表示

2.1 四种机器数

计算机中的数有原码、反码、补码、移码四种表示。正数的原码、反码、补码完全相同；负数的反码是原码符号位不变、其余位取反，补码是反码末位加 1。

为什么用补码：补码把减法统一成加法（A - B = A + (-B)的补码），减法器可以省掉；同时 0 的补码表示唯一，而原码有 +0 和 -0 两个零。这两点是补码成为计算机内部整数标准表示的原因。

n 位机器的表示范围：

编码范围特点
原码/反码-(2(n-1)-1) ~ 2(n-1)-1关于 0 对称，有两个零
补码-2(n-1) ~ 2(n-1)-1负数端多一个，0 唯一
移码补码符号位取反用于浮点数阶码，便于比较大小

典型考法：8 位补码 10000000 的真值是多少？按权展开为 -27 = -128，它没有对应的正数，是补码范围负端的"多出来的那一个"。这类题不要用"取反加一"倒推，直接按位权算最快。

2.2 溢出判断

  • 双符号位（变形补码）：结果 00 正常、01 正溢、10 负溢、11 正常（负数）。
  • 单符号位：最高位进位与次高位进位不同（异或为 1）即溢出。

考试常给"两数相加、问是否溢出、结果是什么"，先判符号位与进位，再决定是否保留结果。

2.3 浮点数

浮点数由阶码和尾数组成：阶码决定表示范围，尾数决定表示精度。这是每年最容易出的概念题。

IEEE 754 标准：

类型符号位阶码尾数总位数偏置值
单精度 float182332127
双精度 double11152641023

规格化数的尾数隐含最高位 1（隐藏位），实际精度比尾数位数多 1 位。阶码用移码表示，便于硬件直接比较两数大小。

判断技巧：题目问"范围"找阶码位数，问"精度"找尾数位数，问"能表示多少个不同值"用 2^总位数 估算。

2.4 校验码

海明码：在 n 位信息位中插入 k 位校验位，需满足 2k ≥ n + k + 1，可检 1 位错并纠 1 位错。

例：8 位信息位需要几位校验位？

  • k=3：23 = 8 < 8+3+1 = 12，不够；
  • k=4：24 = 16 ≥ 8+4+1 = 13，够。

故至少 4 位。这类题不要死记"8 位配 4 位"，每次都代不等式。

CRC 循环冗余校验：用生成多项式做模 2 除法，余数拼在信息码后。信息码后补 0 的个数等于生成多项式的最高次幂，如 G(x)=x³+x+1 补 3 个 0。CRC 检错能力强，但一般不用于纠错。

三、CPU 与体系结构

3.1 CPU 组成与寄存器

CPU = 运算器 + 控制器 + 寄存器组。

  • 运算器：ALU（算术逻辑单元）、累加寄存器 ACC、状态/标志寄存器 PSW。
  • 控制器：程序计数器 PC（下一条指令地址）、指令寄存器 IR（当前指令）、指令译码器、时序部件。
  • 寄存器组：通用寄存器、暂存寄存器。

指令周期：取指 → 间址 → 执行 → 中断，四个阶段并非每条指令都完整经历。

3.2 CISC 与 RISC

对比项CISCRISC
指令数量多、功能复杂少、精简
指令长度变长定长
寻址方式丰富少
访存指令任意指令可访存只有 Load/Store 访存
控制器多为微程序控制多为硬布线控制
流水线不易实现天然友好

RISC 的"精简"是为了让每条指令都能在一个时钟周期内完成，从而把流水线效率做高。

3.3 Flynn 分类

按指令流和数据流的多倍性划分：

类型含义典型
SISD单指令流单数据流传统单处理器
SIMD单指令流多数据流向量机、阵列处理机、GPU
MISD多指令流单数据流理论模型，实际少见
MIMD多指令流多数据流多处理机、多核、集群

3.4 寻址方式

方式操作数位置特点
立即寻址指令中最快，操作数是常量
直接寻址主存，指令给地址一次访存
间接寻址主存，指令给地址的地址两次访存，可扩大寻址范围
寄存器寻址寄存器速度快，不访存
寄存器间接主存，地址在寄存器一次访存
变址寻址主存，变址寄存器 + 形式地址适合数组遍历
相对寻址主存，PC + 偏移适合程序浮动、转移指令
基址寻址主存，基址寄存器 + 偏移适合多道程序重定位

考法：给出指令和寄存器/存储器状态，问"取到的操作数是多少"。按"先找地址、再取内容"的顺序一步步写。

3.5 指令流水线

k 段流水线执行 n 条指令，各段等长（每段 Δt）时：

所需时钟周期 = k + (n - 1)
T = (k + n - 1) × Δt
吞吐率 TP = n / T
加速比 S = 顺序执行时间 / 流水执行时间 = (k × n) / (k + n - 1)

各段耗时不等且不计级间锁存开销（近年真题口径）时：

T = Σti + (n - 1) × max(ti)
Δt = max(ti)；只有各段等长时才化简为 (k + n - 1) × Δt

例 1：5 段流水线、每段 1 个时钟周期、执行 100 条指令。

  • 周期数 = 5 + 99 = 104；
  • 顺序执行需 5 × 100 = 500 周期；
  • 加速比 = 500 / 104 ≈ 4.81，接近段数上限 5。

例 2（2023 上原题口径）：取指 2ns、分析 2ns、执行 1ns，执行 1000 条指令。

  • T = (2+2+1) + 999 × 2 = 2003ns；
  • 直接套 (3+1000-1) × 2 = 2004ns 是把执行段也当成 2ns，属于典型错解。

流水线冲突：结构冲突（硬件资源争用）、数据冲突（后一条依赖前一条结果）、控制冲突（转移指令改变取指方向）。考试若问"影响流水线性能的因素"，答这三类。

四、存储系统

4.1 存储层次与局部性

寄存器 → Cache → 主存 → 辅存，越靠近 CPU 越快、越贵、容量越小。

局部性原理是 Cache 有效的理论基础：

  • 时间局部性：刚被访问的数据/指令很可能再次被访问（循环变量）；
  • 空间局部性：相邻地址的数据很可能被访问（数组、顺序指令）。

4.2 Cache 三种映射

映射方式地址结构冲突比较器特点
直接映射标记 + 行号 + 块内地址冲突多1 个硬件最简单
全相联标记 + 块内地址无冲突全部行最灵活、成本最高
组相联标记 + 组号 + 块内地址组内冲突组内路数折中方案

直接映射地址位数计算：

块内地址位数 = log2(块大小)
行号位数 = log2(Cache 容量 / 块大小)
标记位数 = 主存地址位数 - 行号位数 - 块内地址位数

平均访问时间（未命中时先查 Cache 再访主存）：

平均访问时间 = 命中率 × Cache 时间 + 未命中率 × (Cache 时间 + 主存时间)

例：Cache 2ns、主存 20ns、命中率 95% → 0.95×2 + 0.05×22 = 3.0ns。注意未命中路径要加上查 Cache 的 2ns，这是最常见的失分点。

硬件透明性（真题考点）：主存块与 Cache 行之间的地址映射、命中判断与替换全部由硬件自动完成，操作系统和程序员都看不到，不能用"存储管理软件管理"作答。

4.3 主存编址

主存容量 = 存储单元个数 × 每个单元位数
地址线位数 = log2(存储单元个数)
数据线位数 = 每个单元位数

例：按字节编址、容量 1MB，则单元数 220，地址线 20 根。

4.4 磁盘与 RAID（低频）

  • RAID0：条带化，无冗余，性能最高、可靠性最低；
  • RAID1：镜像，空间利用率 50%，允许一块盘故障；
  • RAID5：分布式奇偶校验，允许一块盘故障，空间利用率 (n-1)/n；
  • RAID6：双校验，允许两块盘故障；
  • RAID10：先镜像再条带，兼顾性能与可靠性。

考试若问"允许一块磁盘故障且利用率较高"，选 RAID5。

五、总线、I/O 与可靠性

5.1 总线

总线作用宽度决定
数据总线传输数据一次能传多少位
地址总线传输地址可寻址空间（2^宽度）
控制总线传输命令、时序、状态—

总线带宽 = 总线宽度（字节）× 总线频率。例：32 位宽、33MHz → 4B × 33M = 132MB/s。

5.2 I/O 四种控制方式

方式CPU 干预程度数据单位特点
程序查询（轮询）全程等待字/字节最简单，CPU 利用率最低
中断每个字/字节中断一次字/字节CPU 与 I/O 并行，但频繁中断开销大
DMA只在传输开始和结束干预数据块数据不经过 CPU，适合高速块设备
通道最少一组数据块专用 I/O 处理器执行通道程序

考法：问"哪种方式 CPU 干预最少"→ 通道；"哪种适合磁盘成块传输"→ DMA；"数据是否经过 CPU"→ DMA 不经过。

地址口径（真题考点）：DMA 控制器与主存直接交换数据，CPU 与 DMA 访问主存时给出的都是主存物理地址，不是 Cache 地址或虚地址。

5.3 可靠性与性能

串联：R = R1 × R2 × … × Rn
并联：R = 1 - (1-R1)(1-R2)…(1-Rn)
MTBF = 1 / 失效率
MIPS = 主频(MHz) / CPI
执行时间 = 指令数 × CPI × 时钟周期

例：3 个部件串联、可靠度均 0.9 → 0.9³ = 0.729；若改为 3 个并联 → 1-0.1³ = 0.999。并联冗余是提高可靠性的主要手段。

例：主频 2GHz、CPI=2 → MIPS = 2000/2 = 1000。

千小时可靠度（真题考点）：R(t) = t 时刻仍正常工作的部件数 / 初始总数，2000 台运行 1000 小时后失效 4 台 → R = 1996/2000 = 0.998；失效率 λ ≈ 失效数/(总数×时间)，MTBF = 1/λ，与串并联系统可靠度不是同一问法。

加权 CPI（真题考点）：多类指令按占比加权，CPĪ = Σ(比例i × CPIi)，如 35%×4 + 45%×2 + 20%×6 = 3.5，主频 2.8GHz 时 MIPS = 2800/3.5 = 800；不要直接把几个 CPI 相加或取算术平均。

八、自检题（能秒答才算过关）

  1. 字长 12 位，补码表示整数，范围是多少？（对应题库 CS-001）
  2. 8 位补码 11111111 的真值是多少？（对应题库 CS-002）
  3. IEEE 754 单精度中，阶码和尾数各多少位？谁决定范围？（对应题库 CS-004）
  4. 16 位信息位用海明码，至少需要几位校验位？（对应题库 CS-006）
  5. 生成多项式 x4 + x + 1，CRC 需在信息码后补几个 0？（对应题库 CS-007）
  6. 5 段流水线、每段 2ns，执行 50 条指令需要多少时间？加速比多少？（对应题库 CS-008 / CS-009）
  7. Cache 4KB、块 16B、主存 1MB，直接映射时标记几位？（对应题库 CS-010）
  8. Cache 存取 1ns、主存 10ns、命中率 90%，未命中先查 Cache，平均访问时间是多少？（对应题库 CS-028）
  9. 三部件串联，可靠度 0.95、0.9、0.9，系统可靠度是多少？（对应题库 CS-014）
  10. 主频 3GHz、CPI=1.5，MIPS 是多少？（对应题库 CS-015）

答案与解析：
1) -2048 ~ 2047。
2) -1（按权展开：-128+64+32+16+8+4+2+1）。
3) 阶码 8 位、尾数 23 位；阶码决定范围。
4) 2k ≥ 16+k+1，k=5 时 32 ≥ 22，故 5 位（k=4 时 16 < 21）。
5) 4 个（最高次为 4）。
6) 周期数 5+49=54，时间 54×2=108ns；加速比 (5×50)/54 ≈ 4.63。
7) 主存 20 位，块内 4 位，行号 log2(4096/16)=8 位，标记 20-8-4=8 位。
8) 0.9×1 + 0.1×11 = 2.0ns。
9) 0.95×0.9×0.9 = 0.7695。
10) 3000/1.5 = 2000。

7Cache 平均访问时间未命中代价按 Tm 计：T = H × Tc + (1-H) × Tm；未命中时先查 Cache 再访存：T = H × Tc + (1-H) × (Tc + Tm)H 为命中率，Tc 为 Cache 访问时间，Tm 为主存访问时间命中率 H = Nc / (Nc + Nm)；Cache 效率 e = Tc / T。审题关键：未命中时若已查过一次 Cache，用第二式
8Cache 直接映射地址划分标记位数 = 主存地址位数 - 行号位数 - 块内地址位数；行号位数 = log2(Cache 容量 / 块大小)；块内地址位数 = log2(块大小)主存地址被切成"标记 + 行号 + 块内地址"三段，行号即 Cache 行（块）的编号先统一单位再取对数。组相联映射把"行号"换成"组号"，全相联映射没有行号段
9主存容量与编址主存容量 = 存储单元个数 × 每个单元位数；地址线位数 = log2(存储单元个数)地址线位数决定寻址空间，数据线位数等于每个单元的位数按字节编址时，存储单元个数 = 容量（以字节计）；32 根地址线可寻址 232 B = 4GB。按字编址需先由字长换算单元数

9.4 指令系统与流水线（10~12）

#公式名称表达式符号含义适用场景 / 备注
10操作码与指令条数等长操作码：指令条数 ≤ 2k；扩展操作码：本级每留出 1 个编码作扩展标志，下级可多出 2d 条指令k 为操作码位数，d 为每次扩展新增的位数指令字长 = 操作码位数 + 各地址码位数之和。扩展编码按"留一扩之"逐级计算，不能直接用 2^总位数
11流水线执行时间各段等长：周期数 = k + (n - 1)、T = (k + n - 1) × Δt；各段不等长：T = Σti + (n - 1) × max(ti)k 为流水段数，n 为指令条数，Δt 为流水线周期；不等长时 max(ti) 为最长段耗时首条指令顺序流过各段，其后每 Δt 完成一条。真题易错：2ns/2ns/1ns 三段跑 1000 条，Σti+999×2=2003ns；套 (k+n-1)×2 会得 2004ns
12流水线加速比与吞吐率等长段：S = k × n / (k + n - 1)；TP = n / T；TP(max) = 1 / ΔtS 为加速比，等于顺序执行时间与流水执行时间之比；TP 为吞吐率，即单位时间完成的指令条数加速比上限趋近段数 k，n 越大越接近；流水线效率 E = n / (k + n - 1)（等长段口径）

配套换算（不计入 12 条）：MIPS = 主频(MHz) / CPI；CPU 执行时间 = 指令数 × CPI × 时钟周期；总线带宽 = 总线宽度(B) × 总线频率。
