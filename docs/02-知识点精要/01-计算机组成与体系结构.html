01 · 计算机组成与体系结构（上午 7 题）

一、必须背下的数值

项目结论
n 位补码范围-2(n-1) ~ 2(n-1)-1
n 位原码/反码范围-(2(n-1)-1) ~ 2(n-1)-1
8 位补码特殊值10000000 = -128（无对应正数）
IEEE 754 单精度1 符号 + 8 阶码 + 23 尾数（32 位）
IEEE 754 双精度1 + 11 + 52（64 位）
移码补码符号位取反
海明码校验位2k ≥ n + k + 1
CRC 补零个数等于生成多项式最高次幂

二、公式表

流水线

k 段流水线执行 n 条指令所需时钟周期 = k + (n - 1)
吞吐率 TP = n / 总时间
加速比 S = 顺序执行时间 / 流水执行时间 = (k × n) / (k + n - 1)

Cache

平均访问时间 = 命中率 × Cache 时间 + 未命中率 × (Cache 时间 + 主存时间)
直接映射地址 = 标记 tag | 行号 | 块内地址
行号位数 = log2(Cache 容量 / 块大小)
块内地址位数 = log2(块大小)

存储与性能

主存容量 = 单元数 × 每单元位数
MIPS = 主频(MHz) / CPI
执行时间 = 指令数 × CPI × 时钟周期

可靠性

串联：R = R1 × R2 × … × Rn
并联：R = 1 - (1-R1)(1-R2)…(1-Rn)
MTBF = 1 / 失效率

  • RISC 与 CISC 的特征区分
  • Flynn 分类（SISD / SIMD / MISD / MIMD）
  • 总线三类的功能、I/O 四种控制方式
  • 串联/并联可靠性计算

四、易混对比

对比项AB
寻址方式多、指令变长CISCRISC 是定长、少寻址
控制方式CISC 多用微程序RISC 多用硬布线
访存指令CISC 任意指令可访存RISC 只有 Load/Store
中断 vs DMA中断每字节/字都要 CPU 介入DMA 成块传输，CPU 只起止干预
直接映射硬件简单、冲突多全相联：灵活、比较器多、成本高

五、自检题（能秒答才算过关）

  1. 字长 12 位，补码表示整数，范围是多少？
  2. 5 段流水线，每段 2ns，执行 50 条指令需要多少时间？加速比多少？
  3. Cache 4KB、块 16B、主存 1MB，直接映射时 tag 几位？
  4. 三部件串联，可靠度 0.95、0.9、0.9，系统可靠度多少？
  5. 生成多项式 x4 + x + 1，CRC 需补几个 0？

答案速查：1) -2048~2047；2) 108ns，加速比 ≈ 4.63；3) 20-8-4=8 位；4) 0.7695；5) 4 个。
