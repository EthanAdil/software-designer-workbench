## 二、线性结构

### 2.1 顺序表与链表

| 对比 | 顺序表 | 链表 |
| --- | --- | --- |
| 存储 | 连续空间 | 离散结点 + 指针 |
| 随机访问 | O(1) | O(n) |
| 插入/删除 | O(n)，平均移动 n/2 | O(1)（已知前驱） |
| 空间 | 可能预留浪费 | 每结点多一个指针开销 |

考试常问"频繁插入删除、很少随机访问"选链表；"需要按下标随机访问"选顺序表。

**二维数组地址（真题考点）**：按行优先时 `地址 = 首址 + 元素大小×(前面完整行数×列数 + 本行前导元素数)`；按列优先时行列互换。例：元素占 2 单元，`A[0][0]=100`、`A[3][3]=220`，由 `100+2(3c+3)=220` 得列数 `c=19`，`A[5][5]=100+2(5×19+5)=300`。

### 2.2 栈与队列

- 栈：后进先出。典型应用是表达式求值、递归调用、括号匹配、进制转换、撤销操作。
- 队列：先进先出。典型应用是 BFS、缓冲区、打印任务排队。

**循环队列**（容量 m，牺牲一个单元判满）：
```
队空：front == rear
队满：(rear + 1) % m == front
元素个数：(rear - front + m) % m
```

### 2.3 串与 KMP

朴素匹配 BF 最坏 O(n×m)：主串每失配一次，模式串回退到开头。

KMP 的核心是 **next 数组**：记录模式串每个位置之前的"最长公共前后缀长度"，失配时模式串跳到 `next[j]` 而不是回到 0，主串指针不回退，时间复杂度 O(n+m)。

考试若问"KMP 相比 BF 的改进"，答"利用已匹配信息，避免主串指针回溯"。

## 三、树与二叉树

### 3.1 基本性质（必背）

| 性质 | 公式 |
| --- | --- |
| 叶子与二度结点 | `n0 = n2 + 1` |
| 第 i 层最多结点 | `2^(i-1)` |
| 高度 h 的二叉树最多结点 | `2^h - 1` |
| n 个结点的完全二叉树高度 | `⌈log2(n+1)⌉` |
| 完全二叉树结点 i 的左/右孩子 | `2i` / `2i+1`（从 1 编号） |
| 完全二叉树结点 i 的父结点 | `⌊i/2⌋` |

`n0 = n2 + 1` 的推导：设结点总数 `n = n0 + n1 + n2`，边数 `n - 1 = n1 + 2n2`，两式联立得 `n0 = n2 + 1`。这个推导只对二叉树成立，不要套到多叉树。

**任意树的通式（真题考点）**：边数 = 结点数 − 1 = Σ各结点度数。例：度为 4 的树有 5 个度 4、8 个度 3、6 个度 2、10 个度 1 的结点，总度数 `20+24+12+10=66`，结点数 `67`，非叶 `29`，叶子 `67−29=38`。

### 3.2 遍历与还原

```
先序：根 → 左 → 右
中序：左 → 根 → 右
后序：左 → 右 → 根
层序：按层从左到右
```

- 先序 + 中序、后序 + 中序、层序 + 中序可以唯一确定二叉树；
- 先序 + 后序不能唯一确定（无法区分只有一个孩子时在左还是在右）。

**还原步骤**：先序的第一个是根，在中序中找到根的位置，左边是左子树、右边是右子树，递归处理。

**两结点先后判定（真题考点）**：中序为"左→根→右"，`n` 排在 `m` 之前当且仅当：`n` 在 `m` 的左子树中、或 `m` 在 `n` 的右子树中、或两者最近公共祖先的两分支里 `n` 位于左支。做题先画相对位置，不要只按编号大小判断。

### 3.3 哈夫曼树

构造：每次从森林中取两个权值最小的树合并，新结点权值为两者之和，重复直到只剩一棵树。

```
WPL = Σ(叶子权值 × 叶子到根的路径长度)
```
哈夫曼编码是最优前缀码，WPL 最小；但编码不唯一（左右子树可交换），只要 WPL 相同即为正确。

**易错（真题考点）**：权值相同的叶子到根的路径长度**不一定**相同——合并次序不同会使同权叶子处在不同深度；"权值相同则路径长度相同"是错误说法。

**例**：权值 `{5,7,8,11,15,25}`。
- 合并 5+7=12 → `{8,11,12,15,25}`；
- 合并 8+11=19 → `{12,15,19,25}`；
- 合并 12+15=27 → `{19,25,27}`；
- 合并 19+25=44 → `{27,44}`；
- 合并 27+44=71。

叶子深度：5、7、8、11 为 3，15、25 为 2。
WPL = `(5+7+8+11)×3 + (15+25)×2 = 31×3 + 40×2 = 173`。

验算技巧：WPL 等于**所有非叶结点权值之和**，即 `12+19+27+44+71 = 173`，两种算法结果一致即可确认。

### 3.4 二叉排序树与平衡树

- BST：左子树 < 根 < 右子树，**中序遍历得到递增序列**；查找平均 O(log n)，退化成链表时 O(n)。
- AVL：任一结点左右子树高度差 ≤ 1。失衡时有四种旋转：LL（右旋）、RR（左旋）、LR（先左后右）、RL（先右后左）。
- 红黑树：近似平衡，插入删除旋转次数少，Java 的 TreeMap、Linux 调度器使用。

### 3.5 B 树与 B+ 树

| 对比 | B 树 | B+ 树 |
| --- | --- | --- |
| 数据位置 | 所有结点都可存数据 | 数据只在叶子结点 |
| 叶子链接 | 无 | 叶子结点成链表 |
| 查找 | 可能在内部结点命中 | 每次都要到叶子 |
| 范围查询 | 不方便 | 沿叶子链表顺序扫描，高效 |
| 典型用途 | 文件索引 | 数据库索引（MySQL InnoDB） |

B 树的阶 m 表示每个结点最多 m 个孩子、m-1 个关键字。数据库选 B+ 树，核心原因是**叶子链表使范围查询和全表扫描更高效，且内部结点不存数据、同样大小能存更多索引项**。

## 四、图

### 4.1 存储结构

| 结构 | 空间 | 适用 | 特点 |
| --- | --- | --- | --- |
| 邻接矩阵 | O(n²) | 稠密图 | 判断两点是否相邻 O(1)；无向图对称 |
| 邻接表 | O(n+e) | 稀疏图 | 找某点所有邻接点快；判断相邻需遍历链表 |

无向图邻接矩阵第 i 行非零个数 = 顶点 i 的度；有向图第 i 行非零个数 = 出度，第 i 列 = 入度。

### 4.2 遍历

- DFS：栈/递归，一条路走到底再回退；
- BFS：队列，按层扩展。

邻接表存储时两种遍历均为 O(n+e)；邻接矩阵为 O(n²)。

### 4.3 最小生成树

| 算法 | 复杂度 | 适用 | 思路 |
| --- | --- | --- | --- |
| Prim | O(n²) | 稠密图 | 从一个顶点出发，每次加入最近的非树顶点 |
| Kruskal | O(e log e) | 稀疏图 | 按边权排序，用并查集避免成环 |

两者都基于贪心，得到的 MST 权值相同（可能不唯一）。

### 4.4 最短路径

- Dijkstra：单源、非负权、O(n²)，贪心；
- Floyd：全源、可含负权（不能有负环）、O(n³)，动态规划；
- Bellman-Ford：单源、可含负权、O(n×e)，可判负环。

**Dijkstra 不能处理负权边**：它一旦确定某点最短距离就不再更新，负权边可能让后续路径更短。

### 4.5 拓扑排序与关键路径

**拓扑排序（AOV 网）**：反复找入度为 0 的顶点输出并删除其出边。若结束后仍有顶点，说明存在环，工程上表示循环依赖。

**关键路径（AOE 网）**：

```
ve（最早发生时间）：从源点正推，取所有前驱路径的最大值
vl（最迟发生时间）：从汇点逆推，取所有后继路径的最小值
活动的最早开始 e = 弧尾的 ve
活动的最迟开始 l = 弧头的 vl - 活动工期
总时差 = l - e，为 0 的活动是关键活动
关键路径 = 从源点到汇点的最长路径，决定最短工期
```

**例**：`v1→v2(3)`、`v1→v3(2)`、`v2→v4(2)`、`v3→v4(4)`、`v4→v5(3)`。

- ve：v1=0，v2=3，v3=2，v4=max(3+2,2+4)=6，v5=6+3=9；
- vl：v5=9，v4=6，v3=6-4=2，v2=6-2=4，v1=min(4-3,2-2)=0；
- 关键活动：a2（v1→v3）、a4（v3→v4）、a5（v4→v5），关键路径 `v1→v3→v4→v5`，工期 9。

总时差为 0 的活动不一定都在同一条路径上，判断关键路径要从源点连到汇点。

## 五、查找

| 方法 | 前提 | 平均复杂度 | 要点 |
| --- | --- | --- | --- |
| 顺序查找 | 无 | O(n) | ASL 成功 = (n+1)/2 |
| 二分查找 | 有序 + 顺序存储 | O(log n) | 最多比较 `⌈log2(n+1)⌉` 次 |
| 二叉排序树 | — | 平均 O(log n)，最坏 O(n) | 中序遍历有序 |
| 散列表 | — | 平均 O(1) | ASL 与装填因子 α 有关 |

**二分查找**：长度为 1000 的有序表，`⌈log2(1001)⌉ = 10`，最多比较 10 次。判定树的高度即最多比较次数。

**判定树与 ASL（真题考点）**：按 `mid = ⌊(low+high)/2⌋` 自顶向下构造判定树，比较序列必须是同一棵树从根到叶的路径；给出一串关键字问"不可能的序列"时，先核对首元素是否为整表中间元素。成功 `ASL = Σ(元素所在层号)/n`，失败 `ASL` 按外部结点逐条探测求平均，不能套 `(n+1)/2`。

**散列表**：装填因子 `α = n/m`（n 为元素数、m 为表长）。α 越大冲突越多、查找越慢。

冲突处理：

- 开放定址：线性探测（冲突后顺序找下一个空位，易产生堆积）、二次探测、双重散列；
- 链地址法：同义词挂链，α 可以大于 1。

**ASL 计算**：成功 ASL = 各元素比较次数之和 / 元素个数；失败 ASL 要按每个散列地址出发探测到空位的次数求平均。考试通常只考成功 ASL。

## 六、排序

| 算法 | 平均 | 最坏 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 快速 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定 |

记忆要点：

- **稳定**：插入、冒泡、归并、基数（口诀"插冒归基"）；
- 快排最坏 O(n²) 出现在序列基本有序、且以首元素为枢轴时；
- 建堆 O(n)，堆排序整体 O(n log n)；取前 k 大用堆最划算；
- 归并排序需要 O(n) 辅助空间，是唯一稳定的 O(n log n) 比较排序；
- 基数排序不是比较排序，适合整数且位数不多。

**一趟划分（真题考点）**：快排以末元素为基准做双指针/挖坑填数，左右指针共扫描约一遍表，时间 `O(n)`、辅助空间 `O(1)`；不要与"快排整体平均 O(nlogn)、递归栈 O(logn)"混答。给定序列问划分结果时，逐位交换并保留基准最终位置。

## 七、算法设计与复杂度

| 策略 | 核心特征 | 典型问题 | 是否保证最优 |
| --- | --- | --- | --- |
| 分治 | 分解 → 递归求解 → 合并 | 归并排序、二分查找、大整数乘法 | 是 |
| 动态规划 | 最优子结构 + 重叠子问题，填表 | 0-1 背包、LCS、矩阵连乘、Floyd | 是 |
| 贪心 | 局部最优推全局最优 | 活动安排、哈夫曼、Prim/Kruskal、分数背包 | 不一定 |
| 回溯 | DFS 搜索解空间树，剪枝 | N 皇后、迷宫、子集和 | 是（穷举） |

**易混**：0-1 背包用动态规划（物品不可分割，贪心会错）；分数背包用贪心（按单位价值排序）。

**复杂度递增**：
```
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2^n) < O(n!)
```

**递推式速判**（主定理的常用结论）：

| 递推式 | 结果 | 典型 |
| --- | --- | --- |
| `T(n)=T(n/2)+O(1)` | O(log n) | 二分查找 |
| `T(n)=2T(n/2)+O(n)` | O(n log n) | 归并排序 |
| `T(n)=2T(n/2)+O(1)` | O(n) | 二叉树遍历 |
| `T(n)=T(n-1)+O(1)` | O(n) | 线性递归 |
| `T(n)=2T(n-1)+O(1)` | O(2^n) | 汉诺塔 |

## 八、速记表

```
n0 = n2 + 1（仅二叉树）
完全二叉树高度 = ⌈log2(n+1)⌉
循环队列元素个数 = (rear - front + m) % m
哈夫曼 WPL = Σ(权值 × 深度)
Prim O(n²) 稠密；Kruskal O(e log e) 稀疏
Dijkstra 单源非负；Floyd 全源 O(n³)
拓扑排序剩顶点 ⇒ 有环
关键路径：ve 取最大、vl 取最小、总时差 0
二分最多比较 ⌈log2(n+1)⌉ 次
稳定排序：插入、冒泡、归并、基数
```

## 九、易错辨析

| 错误认知 | 正确结论 | 原因 |
| --- | --- | --- |
| n0 = n2 + 1 对所有树成立 | 只对二叉树成立 | 多叉树边数与度数的关系不同 |
| 先序 + 后序能唯一确定二叉树 | 不能 | 无法判断单孩子结点在左还是右 |
| 哈夫曼编码唯一 | 编码不唯一，WPL 唯一 | 左右子树可交换 |
| 快排平均和最坏都是 O(n log n) | 最坏 O(n²) | 枢轴划分极不平衡 |
| Dijkstra 可处理负权 | 不能 | 贪心确定后不再更新 |
| 堆排序空间 O(n) | O(1) | 原地排序 |
| 归并排序不稳定 | 稳定 | 合并时相等元素保持原序 |
| 拓扑排序唯一 | 一般不唯一 | 同时有多个入度 0 顶点时顺序可变 |
