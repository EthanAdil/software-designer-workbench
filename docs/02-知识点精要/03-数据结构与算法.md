# 03 · 数据结构与算法（上午 9 题 + 下午 1 题）

## 一、二叉树性质（背死）

| 性质 | 公式 |
| --- | --- |
| 叶子与二度结点 | `n0 = n2 + 1` |
| 第 i 层最多结点 | `2^(i-1)` |
| 高度 h 最多结点 | `2^h - 1` |
| n 个结点完全二叉树高度 | `⌈log2(n+1)⌉` |
| 完全二叉树结点 i 的左/右孩子 | `2i` / `2i+1`（从 1 编号） |
| 完全二叉树结点 i 的父结点 | `⌊i/2⌋` |
| 哈夫曼 WPL | `Σ(权值 × 路径长度)` |

**遍历口诀**：先序"根左右"、中序"左根右"、后序"左右根"。
由"先序 + 中序"或"后序 + 中序"可唯一确定二叉树；"先序 + 后序"不能。

## 二、排序对比表（高频）

| 算法 | 平均 | 最坏 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 直接插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 简单选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 希尔 | O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 快速 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定 |

- 稳定：插入、冒泡、归并、基数
- 快排最坏出现在**基本有序**时（首元素作枢轴）
- 建堆 O(n)，堆排序整体 O(n log n)

## 三、图算法

| 算法 | 用途 | 复杂度 | 适用 |
| --- | --- | --- | --- |
| Prim | 最小生成树 | O(n²) | 稠密图 |
| Kruskal | 最小生成树 | O(e log e) | 稀疏图 |
| Dijkstra | 单源最短路径 | O(n²) | 非负权 |
| Floyd | 全源最短路径 | O(n³) | 小规模 |
| 拓扑排序 | 依赖排序 | O(n+e) | AOV 网 |
| 关键路径 | 最短工期 | O(n+e) | AOE 网 |

**存储选择**：邻接矩阵 O(n²) 适合稠密图；邻接表 O(n+e) 适合稀疏图。
**无向图**：邻接矩阵第 i 行非零个数 = 顶点 i 的度。
**关键路径**：`ve` 取最大、`vl` 取最小，`ve == vl` 的事件在关键路径上，总时差 = `vl - ve - 工期`。

## 四、查找

| 方法 | 前提 | 复杂度 | 要点 |
| --- | --- | --- | --- |
| 顺序查找 | 无 | O(n) | ASL = (n+1)/2 |
| 二分查找 | 有序 + 顺序存储 | O(log n) | 最多比较 `⌈log2(n+1)⌉` 次 |
| 二叉排序树 | — | 平均 O(log n)，最坏 O(n) | 中序遍历有序 |
| 散列表 | — | 平均 O(1) | ASL 与装填因子 α 相关 |

装填因子 `α = n / m`；开放定址要求 α ≤ 0.75 左右；链地址法可 > 1。

## 五、其他必记

```
循环队列元素个数 = (rear - front + m) % m
队空 front == rear；队满 (rear + 1) % m == front（牺牲一个单元）
KMP 时间 O(n + m)，next 数组记录最长公共前后缀
复杂度递增：O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

## 六、算法设计策略

| 策略 | 特征 | 典型题 |
| --- | --- | --- |
| 分治 | 分解 → 递归求解 → 合并 | 归并排序、二分查找、大整数乘法 |
| 动态规划 | 最优子结构 + 重叠子问题 | 背包、LCS、矩阵连乘、最短路径 |
| 贪心 | 局部最优推全局最优 | 活动安排、哈夫曼、最小生成树 |
| 回溯 | DFS 搜索解空间树 | N 皇后、迷宫、子集和 |

## 七、自检题

1. 一棵二叉树有 20 个叶子结点、15 个一度结点，总结点数是多少？
2. 6 个权值 {1,2,3,4,5,6} 构造哈夫曼树，WPL 是多少？
3. 1000 个元素二分查找最多比较几次？
4. 有 5 个顶点的完全无向图有多少条边？
5. 快排递归深度最坏是多少？

> 答案速查：1) n0=n2+1 → n2=19，总数 = 20+15+19 = 54；2) 逐次合并最小两个，WPL = 51；3) 10 次；4) C(5,2) = 10 条；5) O(n)。
