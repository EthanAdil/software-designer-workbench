二、语言基础

2.1 编译与解释

对比编译方式解释方式
过程先整体翻译成目标代码，再执行逐句翻译、逐句执行
执行效率高低
跨平台性差，换平台需重新编译好，有解释器即可
典型C、C++、GoPython、JavaScript、Ruby

编译方式把翻译与运行分开，运行时没有翻译开销，所以快；解释方式不生成目标文件，换平台只需换解释器，所以灵活。考试常问"哪种方式执行效率高/可移植性好"。

2.2 静态类型与动态类型

  • 静态类型：编译期确定并检查类型，如 C、C++、Java、Go；类型错误在编译阶段暴露。
  • 动态类型：运行期才确定类型，如 Python、JavaScript、Ruby；灵活但错误发现晚。

注意"强/弱类型"是另一个维度：强类型不允许隐式跨类型转换，弱类型允许（如 C 的指针与整数互转）。

2.3 语言范型

范型核心思想代表语言
命令式（过程式）用语句改变状态C、Pascal、Fortran
面向对象对象 + 消息，封装继承多态Java、C++、C#
函数式函数是一等公民，无副作用Lisp、Scheme、Haskell
逻辑式声明事实与规则，由系统求解Prolog

2.4 参数传递

方式传递内容能否修改实参说明
传值实参的副本不能C 的默认方式
传地址/引用实参的地址能C 的指针、C++ 的引用
传值-结果传入副本，返回时写回能（返回时）也叫复制-恢复
传名实参表达式文本替换能，且可能重复求值类似宏展开

例：void swap(int a, int b) 以 swap(x, y) 调用，函数内交换的是副本，x、y 不变；改为 swap(int &a, int &b) 才会交换。

传名的陷阱：若实参是 i++，函数体内每引用一次形参就自增一次，最终 i 可能增加多次。这是"传名"最典型的考法。

2.5 作用域与绑定

  • 静态作用域（词法作用域）：变量的可见范围由源代码的嵌套结构决定，编译期即可确定，绝大多数语言采用。
  • 动态作用域：变量可见范围由调用链决定，运行期才能确定，早期 Lisp 使用。
  • 静态绑定（早绑定）：编译期确定调用哪个函数，如重载、非虚方法。
  • 动态绑定（晚绑定）：运行期根据对象实际类型确定，如重写、虚函数。

三、文法与自动机

3.1 乔姆斯基四类文法

类型名称产生式限制识别器用途
0 型短语文法无限制图灵机自然语言、通用计算
1 型上下文有关αAβ → αγβ，γ 非空线性有界自动机少数语言特性
2 型上下文无关A → γ，A 为非终结符下推自动机程序语言语法
3 型正规文法A → aB 或 A → a有限自动机词法规则、正规式

记忆：词法用 3 型（正规式/有限自动机），语法用 2 型（上下文无关文法）。这是编译原理最常考的一句话。

3.2 推导、语法树与二义性

  • 推导：从开始符号出发，反复用产生式替换非终结符，得到句子；
  • 最左推导：每次替换最左边的非终结符；最右推导反之；
  • 语法树：推导的图形表示，叶子是终结符，内部结点是非终结符；
  • 二义性：同一个句子存在两棵不同的语法树（或两个不同的最左推导）。

二义性文法无法用于编译，需要改写文法或增加优先级/结合性规则来消除。

3.3 正规式与有限自动机

概念关键点
DFA每个状态对每个输入符号至多一条转移，无 ε 转移
NFA允许多条转移与 ε 转移
等价性DFA 与 NFA 识别能力相同，都识别正规集
转换NFA 用子集构造法转 DFA；DFA 可最小化
正规式描述词法规则，如 `(a\b)*abb` 表示"以 abb 结尾的 a、b 串"

正规式含义判断：(a|b)*abb 中 (a|b)* 是任意长度的 a/b 串前缀，整体表示所有以 abb 结尾的串。考试常给几个串问"哪个不被该正规式接受"，逐个对照后缀即可。

DFA 的"确定性"：同一状态、同一输入符号，下一状态唯一；与状态数多少、是否有终态无关。

3.4 语法分析方法（低频但偶考）

方法方向特点
递归下降自顶向下为每个非终结符写一个函数，直观、需消除左递归
LL(1)自顶向下预测分析，看 1 个输入符号，要求无左递归、无公共左因子
LR(1)自底向上移进-归约，分析能力强于 LL，能处理更多文法

考试若问"哪种方法能力更强"，答 LR；问"自顶向下的代表"，答递归下降/LL。

四、编译过程

4.1 五个阶段

阶段输入输出用到的理论典型任务
词法分析源程序字符流token 序列正规式、有限自动机识别关键字、标识符、常数
语法分析token 序列语法树上下文无关文法检查结构是否符合文法
语义分析语法树带语义信息的中间表示属性文法类型检查、变量是否声明
中间代码生成与优化中间表示优化的中间代码—四元式、常量合并、循环优化
目标代码生成中间代码目标机器代码—寄存器分配、指令选择

最容易错的一句话："变量是否已声明""运算类型是否匹配"属于语义分析，不是语法分析。语法分析只管结构（括号是否配对、语句是否符合文法），不管含义。

符号表贯穿编译全过程，记录标识符的名字、类型、作用域、存储地址，各阶段都要查表或更新表。

4.2 中间代码

形式说明
四元式(运算符, 操作数1, 操作数2, 结果)，最常用
三元式省略结果，用序号引用中间结果
逆波兰式后缀表达式
树语法树/表达式树
三地址码x = y op z 形式

中间代码的好处：与具体机器无关，便于优化和移植；后端只需针对不同目标机生成代码。

4.3 代码优化

层次例子
局部优化基本块内常量合并、公共子表达式删除、死代码消除
循环优化循环不变式外提、强度削弱（乘法换加法）、循环展开
全局优化全局公共子表达式、代码移动、寄存器分配

强度削弱的典型例子：把循环内的 i*4 换成 i<<2 或累加 4，把乘法降为移位/加法。

五、表达式与程序结构

5.1 中缀转后缀

规则：

  1. 遇操作数直接输出；
  2. 遇运算符，弹出栈中优先级大于或等于当前运算符的全部运算符，再把当前运算符入栈（左结合，同级也弹）；
  3. 遇 ( 直接入栈；遇 ) 弹栈直到 (，括号不输出；
  4. 扫描结束，弹出栈中剩余运算符。

例：

a + b * (c - d)   →   a b c d - * +
(a + b) * c       →   a b + c *
a * (b + c) - d   →   a b c + * d -

5.2 后缀求值

遇操作数入栈；遇运算符弹出两个操作数（先弹出的是右操作数），运算后结果入栈。

3 4 + 5 * → 先算 3+4=7，再算 7×5=35。

5.3 表达式树

表达式树的中序遍历是原中缀表达式，后序遍历是后缀表达式，前序遍历是前缀表达式。题目给出表达式树问遍历结果时，按"左-根-右"等规则直接读。

5.4 程序结构

结构化程序设计的三种基本控制结构：顺序、选择、循环。GOTO 语句破坏结构化，应避免。结构化设计强调单入口、单出口，便于验证与维护。

八、自检题

  1. 词法分析用什么理论？语法分析用什么文法？（对应题库 PL-019 / PL-005）
  2. a*(b+c)-d 的后缀表达式是什么？（对应题库 PL-032）
  3. DFA 与 NFA 的本质区别是什么？（对应题库 PL-029）
  4. "数组下标越界检查"属于哪个阶段？（对应题库 PL-008）
  5. 编译方式与解释方式各自的优缺点？（对应题库 PL-001）
  6. 传名调用为什么可能让实参被多次求值？（对应题库 PL-027）
  7. 乔姆斯基 2 型文法对应哪种自动机？（对应题库 PL-030）
  8. (a|b)*abb 是否接受串 aabb？是否接受 abab？（对应题库 PL-003）
  9. 四元式与三元式的主要区别是什么？（对应题库 PL-031）
  10. 循环不变式外提属于哪类优化？（对应题库 PL-021）

答案与解析：
1) 正规式/有限自动机；上下文无关文法（2 型）。
2) a b c + * d -。
3) DFA 每个状态对每个输入至多一条转移且无 ε 边；NFA 允许多条与 ε 转移。
4) 语义分析（若强调运行期检查，则属于运行时支撑，考试按语义分析答）。
5) 编译执行快、跨平台差；解释灵活、跨平台好但慢。
6) 传名是文本替换，形参在函数体每出现一次就重新求值一次。
7) 下推自动机。
8) aabb 接受（以 abb 结尾）；abab 不接受（不以 abb 结尾）。
9) 四元式显式给出结果变量，三元式用序号引用中间结果、不产生新变量。
10) 循环优化。
