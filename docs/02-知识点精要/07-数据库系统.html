一、三级模式与两级映像

模式别名描述数量
外模式子模式 / 用户模式用户看到的数据视图多个
模式概念模式 / 逻辑模式全体数据的逻辑结构一个
内模式存储模式物理存储结构一个
映像保证
外模式/模式逻辑独立性（逻辑结构变，用户视图不变）
模式/内模式物理独立性（存储变，逻辑结构不变）

二、ER 模型转换

联系类型转换方式
1:1可合并到任一端，把另一端主键作为外键
1:n把 1 端主键放入 n 端作外键
m:n必须独立建表，主键为两端主键的组合，可携带联系属性
  • 多值属性：单独成表
  • 弱实体：依赖强实体的主键
  • ER 图合并冲突：属性冲突、命名冲突、结构冲突

四、规范化

范式要求消除的问题
1NF属性不可再分非原子属性
2NF1NF + 消除非主属性对码的部分依赖部分依赖
3NF2NF + 消除非主属性对码的传递依赖传递依赖
BCNF所有非平凡函数依赖的决定因素都是候选键主属性对码的依赖

候选键求解（闭包法）：从每个属性/属性组出发求闭包，若闭包包含全部属性且无冗余，则为候选键。

无损连接分解判定：R1 ∩ R2 → R1 - R2 或 R1 ∩ R2 → R2 - R1 成立。

五、SQL 要点

-- 执行顺序：FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY
SELECT 列, 聚合函数
FROM 表 [JOIN 表 ON 条件]
WHERE 行条件
GROUP BY 分组列
HAVING 分组后条件
ORDER BY 排序列 [ASC|DESC];
类别语句
DDLCREATE / ALTER / DROP
DMLSELECT / INSERT / UPDATE / DELETE
DCLGRANT / REVOKE
事务COMMIT / ROLLBACK / SAVEPOINT

经典写法

-- 每门课平均分 > 80
SELECT 课程号, AVG(成绩) FROM 选课 GROUP BY 课程号 HAVING AVG(成绩) > 80;

-- 没被选修的课程
SELECT * FROM 课程 WHERE 课程号 NOT IN (SELECT 课程号 FROM 选课);

-- 尚未归还
SELECT * FROM 借阅 WHERE 归还日期 IS NULL;

-- 前 3 名
SELECT 工号, SUM(工时) AS 总工时 FROM 参与 GROUP BY 工号 ORDER BY 总工时 DESC LIMIT 3;

六、事务与并发

ACID：原子性、一致性、隔离性、持久性。

隔离级别脏读不可重复读幻读
READ UNCOMMITTED可能可能可能
READ COMMITTED不会可能可能
REPEATABLE READ不会不会可能
SERIALIZABLE不会不会不会

封锁：共享锁 S（读）、排他锁 X（写）。
两段锁协议：扩展阶段只加锁、收缩阶段只解锁；遵守 2PL 的调度一定可串行化，但可能死锁。
死锁预防：一次封锁法、顺序封锁法。

备份恢复：静态/动态转储、海量/增量转储、日志（UNDO 撤销未提交、REDO 重做已提交）、检查点。

七、自检题

  1. 逻辑独立性由哪个映像保证？
  2. R(A,B,C)，F={A→B, B→C}，候选键是什么？
  3. m:n 联系转关系模式时主键怎么定？
  4. 哪种隔离级别能避免幻读？
