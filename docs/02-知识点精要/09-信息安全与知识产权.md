> 这两个模块合计 6 题，全部是记忆型，适合考前 4~6 周集中处理，投入产出比极高。

## 一、密码学

| 类型 | 算法 | 密钥长度 | 用途 |
| --- | --- | --- | --- |
| 对称 | DES | 56 位 | 数据加密 |
| 对称 | 3DES | 112/168 位 | 兼容旧系统 |
| 对称 | AES | 128/192/256 位 | 主流对称加密 |
| 对称 | IDEA、RC4 | — | 特定场景 |
| 非对称 | RSA | 1024/2048 位 | 加密、签名、密钥交换 |
| 非对称 | ECC | 较短 | 移动端、资源受限 |
| 非对称 | DSA | — | 仅用于签名 |
| 哈希 | MD5 | 输出 128 位 | 完整性校验（已不推荐） |
| 哈希 | SHA-1 | 输出 160 位 | 完整性校验 |
| 哈希 | SHA-256 | 输出 256 位 | 当前主流 |

**方向不要记反**

```
加密传输：发送方用【接收方公钥】加密 → 接收方用【自己私钥】解密
数字签名：发送方用【自己私钥】签名 → 接收方用【发送方公钥】验证
```

数字签名保证**完整性 + 不可否认性**，但不保证机密性。
哈希是单向的，**不能解密**，不属于加密算法。
MAC/HMAC 用共享密钥保证完整性与认证，但**不提供不可否认性**。

## 二、认证与安全体系

| 概念 | 作用 |
| --- | --- |
| 数字证书 | 由 CA 签发，绑定公钥与持有者身份，防中间人 |
| PKI | CA、RA、证书库、CRL、密钥管理 |
| 防火墙（包过滤） | 网络层检查地址与端口，快但粗 |
| 防火墙（应用代理） | 应用层解析内容，细但慢 |
| IDS | 被动检测并告警 |
| IPS | 主动检测并阻断 |
| VPN（IPSec） | 网络层，AH/ESP |
| VPN（SSL） | 应用层，浏览器即可 |
| 等级保护 | 分五级，一级最低 |

**信息安全五要素**：机密性、完整性、可用性、可控性、不可否认性。

**常见攻击**：DDoS、ARP 欺骗、DNS 劫持、SQL 注入、XSS、CSRF、暴力破解、重放攻击、社会工程。

**恶意代码**：病毒（需宿主）、蠕虫（自主传播）、木马（远控后门）、逻辑炸弹（条件触发）。

## 三、标准化

| 代号 | 含义 |
| --- | --- |
| GB | 强制性国家标准 |
| GB/T | 推荐性国家标准 |
| GJB | 国家军用标准 |
| DB | 地方标准 |

**组织**：ISO（国际标准化组织）、IEC（国际电工委员会）、ITU-T（国际电信联盟）、IEEE（美国电气电子工程师学会）。
标准有效期一般 5 年，需复审。

## 四、知识产权（四组数字必背）

| 权利 | 保护期 |
| --- | --- |
| 著作权（署名权、修改权、保护作品完整权） | **永久** |
| 著作权（发表权、财产权，自然人） | 作者终生 + 死后 **50 年** |
| 著作权（法人作品） | 首次发表后 **50 年** |
| 发明专利 | **20 年**（自申请日） |
| 实用新型 | **10 年** |
| 外观设计 | **15 年**（2021 年修法后） |
| 商标 | **10 年**，可无限次续展 |
| 商业秘密 | 无期限，需采取保密措施 |

**归属规则**

| 场景 | 归属 |
| --- | --- |
| 委托开发，合同有约定 | 按约定 |
| 委托开发，**无约定** | **受托方（开发者）** |
| 职务作品（一般） | 作者，单位有两年优先使用权 |
| 职务作品（主要利用单位物质技术条件、单位担责） | 作者仅署名权，其余归单位 |
| 软件著作权保护对象 | 程序及其文档（不保护思想、算法、处理过程） |

## 五、自检题

1. 数字签名用谁的私钥？验证用谁的公钥？
2. 要避免"读脏数据"，隔离级别至少是什么？
3. 委托开发无约定时著作权归谁？
4. 外观设计专利保护期是多少年？
5. 蠕虫与病毒的核心区别？

> 答案速查：1) 发送方私钥签名，发送方公钥验证；2) READ COMMITTED；3) 受托方；4) 15 年；5) 蠕虫可独立运行并自主传播，病毒需寄生宿主。
