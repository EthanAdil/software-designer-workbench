对应知识模块要点：云计算与大数据；人工智能与机器学习；物联网、区块链与新兴应用
范围：要点即出题范围（题库逐题标注 points）；要点之外的细节为加深内容，只求理解，不单独出题。

二、云计算

2.1 定义与特征

云计算通过网络按需提供可配置的计算资源（网络、服务器、存储、应用、服务），用户按使用量付费。

五个基本特征：

  1. 按需自服务：用户自助申请，无需人工干预；
  2. 广泛网络接入：通过标准网络访问；
  3. 资源池化：资源以池的形式共享，多租户隔离；
  4. 快速弹性：可快速扩容与缩容；
  5. 服务可计量：按使用量计费与监控。

2.2 三种服务模式

模式提供内容用户负责典型例子
IaaS虚拟机、存储、网络等基础设施操作系统、中间件、应用、数据AWS EC2、阿里云 ECS
PaaS开发运行平台、中间件、数据库服务应用与数据Google App Engine、Heroku
SaaS可直接使用的软件只管使用与配置Office 365、企业邮箱、在线 CRM

判断技巧：用户是否要管操作系统——要管是 IaaS；不管 OS 但要部署自己的应用是 PaaS；连应用都不用开发、直接使用是 SaaS。

2.3 部署形态

形态特点
公有云云服务商运营，多租户共享，成本低
私有云企业自建自用，安全可控，成本高
混合云关键业务私有云、弹性业务公有云
社区云特定群体（如某行业）共同使用

2.4 虚拟化与容器

对比虚拟机容器
隔离层次硬件级，含完整 Guest OS进程级，共享宿主机内核
启动速度分钟级秒级
资源开销大小
隔离性强较弱
典型VMware、KVMDocker、containerd

云原生四要素：容器化、微服务、DevOps、持续交付。Kubernetes 是容器编排的事实标准，负责调度、扩缩容、服务发现。

三、大数据

3.1 4V 特征

特征含义
Volume数据体量大（TB/PB 级）
Velocity产生与处理速度快，实时性要求高
Variety类型多样：结构化、半结构化、非结构化
Value价值密度低，需从海量数据中挖掘

扩展的第五个 V 是 Veracity（真实性/质量），强调数据可信度。

3.2 处理流程

数据采集 → 预处理（清洗、集成、变换、归约）→ 存储 → 分析挖掘 → 可视化

3.3 Hadoop 生态

组件作用
HDFS分布式文件系统，NameNode 管元数据、DataNode 存数据块，多副本
MapReduce批处理计算模型，Map 分片处理、Reduce 汇总
YARN资源调度，ResourceManager 全局、NodeManager 单机
Hive类 SQL 数据仓库，把 SQL 转为 MapReduce/Spark 任务
HBase基于 HDFS 的列式 NoSQL 数据库，适合随机读写
Spark内存计算，比 MapReduce 快，支持批处理与流处理

3.4 批处理与流处理

类型数据形态延迟典型
批处理有界、已落地分钟~小时MapReduce、Hive
流处理无界、持续到达毫秒~秒Flink、Spark Streaming、Storm

数据仓库 vs 数据湖：数据仓库存结构化、已建模数据（schema-on-write），适合 BI 报表；数据湖存原始数据（schema-on-read），适合探索式分析与机器学习。

四、人工智能

4.1 三大研究取向

取向核心思想代表
符号主义用符号与逻辑规则模拟智能专家系统、知识图谱、逻辑推理
连接主义用神经网络模拟大脑连接深度学习、大模型
行为主义智能体在与环境交互中学习强化学习、机器人

4.2 机器学习分类

类型数据任务典型算法
监督学习有标签分类、回归线性回归、逻辑回归、决策树、SVM、KNN、随机森林
无监督学习无标签聚类、降维K-means、DBSCAN、PCA
半监督学习少量标签 + 大量无标签分类自训练、图半监督
强化学习奖励信号序列决策Q-learning、DQN、策略梯度

4.3 深度学习主干

结构擅长典型应用
CNN图像、局部特征、卷积与池化图像分类、目标检测、人脸识别
RNN/LSTM序列、时序依赖语音识别、文本生成、股价预测
Transformer自注意力、长距离依赖、可并行机器翻译、大语言模型、多模态

4.4 大模型与生成式 AI

  • 预训练：在海量无标注语料上自监督学习，得到基础模型；
  • 微调（SFT）：用标注数据调整模型以适应具体任务；
  • RLHF：基于人类反馈的强化学习，使输出更符合人类偏好；
  • 提示工程：通过设计输入提示引导模型输出；
  • RAG（检索增强生成）：先检索外部知识库再生成，缓解幻觉、保证时效性；
  • 幻觉：模型生成看似合理但与事实不符的内容，是大模型的主要风险之一。

常见应用：计算机视觉、自然语言处理（翻译、摘要、问答）、语音识别与合成、推荐系统、自动驾驶。

4.5 过拟合与评估

过拟合：模型在训练集表现好、测试集表现差。对策：增加数据、正则化（L1/L2）、Dropout、早停、交叉验证、简化模型。

评估指标：准确率、精确率、召回率、F1、ROC-AUC；回归用 MSE/MAE/R²。

五、物联网与 5G

5.1 物联网架构

层次作用典型技术/设备
感知层数据采集与识别传感器、RFID、二维码、摄像头
网络层数据传输NB-IoT、LoRa、ZigBee、4G/5G
平台层设备管理、数据汇聚物联网平台、边缘网关
应用层业务呈现智能家居、车联网、工业互联网

三特征：全面感知、可靠传输、智能处理。

5.2 物联网通信技术

技术特点适用
NB-IoT窄带、低功耗、广覆盖、大连接、成本低抄表、井盖、环境监测
LoRa远距离、低功耗、自组网园区、农业
ZigBee短距离、低功耗、Mesh 组网智能家居
5G高速率、低时延、大连接车联网、工业控制

5.3 5G 三大场景

场景全称特点应用
eMBB增强移动宽带高速率4K/8K 视频、VR/AR
mMTC海量机器类通信高连接密度、低功耗智慧城市、传感器网络
uRLLC低时延高可靠毫秒级时延、高可靠远程手术、车联网、工业控制

六、区块链与边缘计算

6.1 区块链特征

特征含义
去中心化无单一中心节点，节点共同维护
不可篡改区块哈希链式相连，修改需重算后续所有区块
可追溯每笔交易有完整历史记录
公开透明公有链数据对所有节点可见
集体维护共识机制保证各节点账本一致

核心技术：哈希链、数字签名、共识机制、智能合约、P2P 网络。

6.2 三种链与共识机制

类型准入典型特点
公有链任何人可加入比特币、以太坊完全去中心化，性能较低
联盟链许可节点加入Hyperledger Fabric多机构共享，兼顾效率与可控
私有链单一组织内部企业内部账本中心化程度高，性能好
共识机制原理适用
PoW算力竞争解题，最长链胜出公有链，能耗高
PoS按权益（持币量）选记账人公有链，能耗低
PBFT多轮投票达成拜占庭容错联盟链，确定性强、节点数受限

不可能三角：去中心化、安全性、可扩展性三者难以同时最优。

智能合约：部署在链上的自动执行代码，条件满足即触发，不可篡改。

6.3 边缘计算

把计算、存储、网络能力下沉到靠近数据源的一侧（网关、基站、设备），就近处理。

价值：降低时延、减少回传带宽、本地数据不出域（隐私）、支持离线自治。与云计算是云边协同关系：边缘做实时处理，云端做全局分析与模型训练。

相关概念：数字孪生（物理实体的虚拟映射）、AR/VR（增强/虚拟现实）、微服务（独立部署的小服务）、容器编排（Kubernetes）。

八、易错辨析

错误认知正确结论原因
IaaS 提供开发平台IaaS 只提供基础设施，PaaS 才提供平台责任边界不同
SaaS 需要用户部署应用SaaS 直接使用软件应用由服务商托管
大数据价值密度高价值密度低，需挖掘单条数据价值有限
容器是轻量虚拟机容器共享宿主机内核，不是虚拟化硬件隔离机制不同
无监督学习需要标签不需要标签聚类/降维靠数据相似性
Transformer 只能做文本也可用于图像、多模态自注意力是通用结构
区块链绝对安全存在 51% 攻击、合约漏洞等风险不可篡改依赖共识
边缘计算替代云计算云边协同，不是替代各自承担不同任务
NB-IoT 适合视频监控NB-IoT 带宽低，适合小数据视频需高带宽

  10. 公有链与联盟链的共识机制有何不同？（对应题库 TECH-010）
  11. 边缘计算的核心价值是什么？（对应题库 TECH-012）
  12. RAG 能缓解大模型的什么问题？（对应题库 TECH-008）

答案与解析：
1) SaaS。
2) 容器共享宿主机内核、启动快、开销小；虚拟机含完整 Guest OS、隔离性强。
3) Volume 体量大、Velocity 速度快、Variety 类型多、Value 价值密度低；单条数据价值有限，需大规模分析提炼。
4) NameNode 管理命名空间与元数据；DataNode 存储数据块并定期汇报。
5) 流处理（Flink/Spark Streaming）。
6) 无监督学习。
7) CNN 图像、RNN 序列、Transformer 长距离依赖与并行（大模型基础）。
8) 感知层（传感器、RFID、摄像头）、网络层（NB-IoT、LoRa、5G）、应用层（智能家居、车联网等）。
9) eMBB 高速率、mMTC 大连接、uRLLC 低时延高可靠。
10) 公有链常用 PoW/PoS，开放但性能较低；联盟链常用 PBFT，节点受控、确定性强。
11) 就近处理，降低时延与回传带宽，保护本地数据隐私，与云端协同。
12) 缓解幻觉、补充时效性知识（先检索外部知识再生成）。
