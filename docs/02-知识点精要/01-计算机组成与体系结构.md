## 二、数据表示

### 2.1 四种机器数

计算机中的数有原码、反码、补码、移码四种表示。正数的原码、反码、补码完全相同；负数的反码是原码符号位不变、其余位取反，补码是反码末位加 1。

**为什么用补码**：补码把减法统一成加法（`A - B = A + (-B)的补码`），减法器可以省掉；同时 0 的补码表示唯一，而原码有 `+0` 和 `-0` 两个零。这两点是补码成为计算机内部整数标准表示的原因。

n 位机器的表示范围：

| 编码 | 范围 | 特点 |
| --- | --- | --- |
| 原码/反码 | `-(2^(n-1)-1) ~ 2^(n-1)-1` | 关于 0 对称，有两个零 |
| 补码 | `-2^(n-1) ~ 2^(n-1)-1` | 负数端多一个，0 唯一 |
| 移码 | 补码符号位取反 | 用于浮点数阶码，便于比较大小 |

**典型考法**：8 位补码 `10000000` 的真值是多少？按权展开为 `-2^7 = -128`，它没有对应的正数，是补码范围负端的"多出来的那一个"。这类题不要用"取反加一"倒推，直接按位权算最快。

### 2.2 溢出判断

- **双符号位（变形补码）**：结果 `00` 正常、`01` 正溢、`10` 负溢、`11` 正常（负数）。
- **单符号位**：最高位进位与次高位进位不同（异或为 1）即溢出。

考试常给"两数相加、问是否溢出、结果是什么"，先判符号位与进位，再决定是否保留结果。

### 2.3 浮点数

浮点数由阶码和尾数组成：**阶码决定表示范围，尾数决定表示精度**。这是每年最容易出的概念题。

IEEE 754 标准：

| 类型 | 符号位 | 阶码 | 尾数 | 总位数 | 偏置值 |
| --- | --- | --- | --- | --- | --- |
| 单精度 float | 1 | 8 | 23 | 32 | 127 |
| 双精度 double | 1 | 11 | 52 | 64 | 1023 |

规格化数的尾数隐含最高位 1（隐藏位），实际精度比尾数位数多 1 位。阶码用移码表示，便于硬件直接比较两数大小。

**判断技巧**：题目问"范围"找阶码位数，问"精度"找尾数位数，问"能表示多少个不同值"用 `2^总位数` 估算。

### 2.4 校验码

**海明码**：在 n 位信息位中插入 k 位校验位，需满足 `2^k ≥ n + k + 1`，可检 1 位错并纠 1 位错。

例：8 位信息位需要几位校验位？
- k=3：`2^3 = 8 < 8+3+1 = 12`，不够；
- k=4：`2^4 = 16 ≥ 8+4+1 = 13`，够。
故至少 4 位。这类题不要死记"8 位配 4 位"，每次都代不等式。

**CRC 循环冗余校验**：用生成多项式做模 2 除法，余数拼在信息码后。**信息码后补 0 的个数等于生成多项式的最高次幂**，如 `G(x)=x³+x+1` 补 3 个 0。CRC 检错能力强，但一般不用于纠错。

## 三、CPU 与体系结构

### 3.1 CPU 组成与寄存器

CPU = 运算器 + 控制器 + 寄存器组。

- 运算器：ALU（算术逻辑单元）、累加寄存器 ACC、状态/标志寄存器 PSW。
- 控制器：程序计数器 PC（下一条指令地址）、指令寄存器 IR（当前指令）、指令译码器、时序部件。
- 寄存器组：通用寄存器、暂存寄存器。

**指令周期**：取指 → 间址 → 执行 → 中断，四个阶段并非每条指令都完整经历。

### 3.2 CISC 与 RISC

| 对比项 | CISC | RISC |
| --- | --- | --- |
| 指令数量 | 多、功能复杂 | 少、精简 |
| 指令长度 | 变长 | 定长 |
| 寻址方式 | 丰富 | 少 |
| 访存指令 | 任意指令可访存 | 只有 Load/Store 访存 |
| 控制器 | 多为微程序控制 | 多为硬布线控制 |
| 流水线 | 不易实现 | 天然友好 |

RISC 的"精简"是为了让每条指令都能在一个时钟周期内完成，从而把流水线效率做高。

### 3.3 Flynn 分类

按**指令流**和**数据流**的多倍性划分：

| 类型 | 含义 | 典型 |
| --- | --- | --- |
| SISD | 单指令流单数据流 | 传统单处理器 |
| SIMD | 单指令流多数据流 | 向量机、阵列处理机、GPU |
| MISD | 多指令流单数据流 | 理论模型，实际少见 |
| MIMD | 多指令流多数据流 | 多处理机、多核、集群 |

### 3.4 寻址方式

| 方式 | 操作数位置 | 特点 |
| --- | --- | --- |
| 立即寻址 | 指令中 | 最快，操作数是常量 |
| 直接寻址 | 主存，指令给地址 | 一次访存 |
| 间接寻址 | 主存，指令给地址的地址 | 两次访存，可扩大寻址范围 |
| 寄存器寻址 | 寄存器 | 速度快，不访存 |
| 寄存器间接 | 主存，地址在寄存器 | 一次访存 |
| 变址寻址 | 主存，变址寄存器 + 形式地址 | 适合数组遍历 |
| 相对寻址 | 主存，PC + 偏移 | 适合程序浮动、转移指令 |
| 基址寻址 | 主存，基址寄存器 + 偏移 | 适合多道程序重定位 |

考法：给出指令和寄存器/存储器状态，问"取到的操作数是多少"。按"先找地址、再取内容"的顺序一步步写。

### 3.5 指令流水线

k 段流水线执行 n 条指令：

```
所需时钟周期 = k + (n - 1)
吞吐率 TP = n / 总时间
加速比 S = 顺序执行时间 / 流水执行时间 = (k × n) / (k + n - 1)
```

**例**：5 段流水线、每段 1 个时钟周期、执行 100 条指令。
- 周期数 = 5 + 99 = 104；
- 顺序执行需 5 × 100 = 500 周期；
- 加速比 = 500 / 104 ≈ 4.81，接近段数上限 5。

**流水线冲突**：结构冲突（硬件资源争用）、数据冲突（后一条依赖前一条结果）、控制冲突（转移指令改变取指方向）。考试若问"影响流水线性能的因素"，答这三类。

## 四、存储系统

### 4.1 存储层次与局部性

寄存器 → Cache → 主存 → 辅存，越靠近 CPU 越快、越贵、容量越小。

**局部性原理**是 Cache 有效的理论基础：
- 时间局部性：刚被访问的数据/指令很可能再次被访问（循环变量）；
- 空间局部性：相邻地址的数据很可能被访问（数组、顺序指令）。

### 4.2 Cache 三种映射

| 映射方式 | 地址结构 | 冲突 | 比较器 | 特点 |
| --- | --- | --- | --- | --- |
| 直接映射 | 标记 + 行号 + 块内地址 | 冲突多 | 1 个 | 硬件最简单 |
| 全相联 | 标记 + 块内地址 | 无冲突 | 全部行 | 最灵活、成本最高 |
| 组相联 | 标记 + 组号 + 块内地址 | 组内冲突 | 组内路数 | 折中方案 |

**直接映射地址位数计算**：
```
块内地址位数 = log2(块大小)
行号位数 = log2(Cache 容量 / 块大小)
标记位数 = 主存地址位数 - 行号位数 - 块内地址位数
```

**平均访问时间**（未命中时先查 Cache 再访主存）：
```
平均访问时间 = 命中率 × Cache 时间 + 未命中率 × (Cache 时间 + 主存时间)
```
例：Cache 2ns、主存 20ns、命中率 95% → `0.95×2 + 0.05×22 = 3.0ns`。注意未命中路径要加上查 Cache 的 2ns，这是最常见的失分点。

### 4.3 主存编址

```
主存容量 = 存储单元个数 × 每个单元位数
地址线位数 = log2(存储单元个数)
数据线位数 = 每个单元位数
```
例：按字节编址、容量 1MB，则单元数 `2^20`，地址线 20 根。

### 4.4 磁盘与 RAID（低频）

- RAID0：条带化，无冗余，性能最高、可靠性最低；
- RAID1：镜像，空间利用率 50%，允许一块盘故障；
- RAID5：分布式奇偶校验，允许一块盘故障，空间利用率 `(n-1)/n`；
- RAID6：双校验，允许两块盘故障；
- RAID10：先镜像再条带，兼顾性能与可靠性。

考试若问"允许一块磁盘故障且利用率较高"，选 RAID5。

## 五、总线、I/O 与可靠性

### 5.1 总线

| 总线 | 作用 | 宽度决定 |
| --- | --- | --- |
| 数据总线 | 传输数据 | 一次能传多少位 |
| 地址总线 | 传输地址 | 可寻址空间（2^宽度） |
| 控制总线 | 传输命令、时序、状态 | — |

**总线带宽 = 总线宽度（字节）× 总线频率**。例：32 位宽、33MHz → `4B × 33M = 132MB/s`。

### 5.2 I/O 四种控制方式

| 方式 | CPU 干预程度 | 数据单位 | 特点 |
| --- | --- | --- | --- |
| 程序查询（轮询） | 全程等待 | 字/字节 | 最简单，CPU 利用率最低 |
| 中断 | 每个字/字节中断一次 | 字/字节 | CPU 与 I/O 并行，但频繁中断开销大 |
| DMA | 只在传输开始和结束干预 | 数据块 | 数据不经过 CPU，适合高速块设备 |
| 通道 | 最少 | 一组数据块 | 专用 I/O 处理器执行通道程序 |

考法：问"哪种方式 CPU 干预最少"→ 通道；"哪种适合磁盘成块传输"→ DMA；"数据是否经过 CPU"→ DMA 不经过。

### 5.3 可靠性与性能

```
串联：R = R1 × R2 × … × Rn
并联：R = 1 - (1-R1)(1-R2)…(1-Rn)
MTBF = 1 / 失效率
MIPS = 主频(MHz) / CPI
执行时间 = 指令数 × CPI × 时钟周期
```

例：3 个部件串联、可靠度均 0.9 → `0.9³ = 0.729`；若改为 3 个并联 → `1-0.1³ = 0.999`。并联冗余是提高可靠性的主要手段。

例：主频 2GHz、CPI=2 → `MIPS = 2000/2 = 1000`。

## 六、速记表

| 项目 | 结论 |
| --- | --- |
| n 位补码范围 | `-2^(n-1) ~ 2^(n-1)-1` |
| n 位原码/反码范围 | `-(2^(n-1)-1) ~ 2^(n-1)-1` |
| 8 位补码特殊值 | `10000000 = -128` |
| IEEE 754 单精度 | 1 + 8 + 23 = 32 位，偏置 127 |
| IEEE 754 双精度 | 1 + 11 + 52 = 64 位，偏置 1023 |
| 移码 | 补码符号位取反 |
| 海明码 | `2^k ≥ n + k + 1` |
| CRC 补零 | 等于生成多项式最高次幂 |
| 流水线周期数 | `k + (n-1)` |
| 加速比 | `(k×n) / (k+n-1)` |
| 直接映射标记位 | 主存地址位 - 行号位 - 块内地址位 |
| 总线带宽 | 宽度（字节）× 频率 |
| 串联/并联可靠度 | 乘积 / `1-∏(1-Ri)` |

## 七、易错辨析

| 错误认知 | 正确结论 | 原因 |
| --- | --- | --- |
| 补码范围关于 0 对称 | 负数端多一个 `-2^(n-1)` | 0 只占一个编码，负数多占一个 |
| 阶码决定精度、尾数决定范围 | 说反了：阶码定范围、尾数定精度 | 阶码是 2 的指数，尾数是有效数字 |
| 流水线加速比分母是单条指令时间 | 分母是流水执行总时间 | 加速比比较的是"整批任务"的耗时 |
| Cache 未命中只算主存时间 | 要加上查 Cache 的时间 | 未命中时 Cache 已经查过一次 |
| DMA 传输的数据经过 CPU | DMA 数据直接在设备与主存间传送 | CPU 只做初始化与结束处理 |
| 地址总线宽度决定数据传送速度 | 地址线决定寻址空间，数据线决定一次传输位数 | 两者作用不同 |

## 八、自检题（能秒答才算过关）

1. 字长 12 位，补码表示整数，范围是多少？
2. 8 位补码 `11111111` 的真值是多少？
3. IEEE 754 单精度中，阶码和尾数各多少位？谁决定范围？
4. 16 位信息位用海明码，至少需要几位校验位？
5. 生成多项式 `x^4 + x + 1`，CRC 需在信息码后补几个 0？
6. 5 段流水线、每段 2ns，执行 50 条指令需要多少时间？加速比多少？
7. Cache 4KB、块 16B、主存 1MB，直接映射时标记几位？
8. Cache 存取 1ns、主存 10ns、命中率 90%，未命中先查 Cache，平均访问时间是多少？
9. 三部件串联，可靠度 0.95、0.9、0.9，系统可靠度是多少？
10. 主频 3GHz、CPI=1.5，MIPS 是多少？

> 答案与解析：
> 1) `-2048 ~ 2047`。
> 2) `-1`（按权展开：-128+64+32+16+8+4+2+1）。
> 3) 阶码 8 位、尾数 23 位；阶码决定范围。
> 4) `2^k ≥ 16+k+1`，k=5 时 32 ≥ 22，故 5 位（k=4 时 16 < 21）。
> 5) 4 个（最高次为 4）。
> 6) 周期数 `5+49=54`，时间 `54×2=108ns`；加速比 `(5×50)/54 ≈ 4.63`。
> 7) 主存 20 位，块内 4 位，行号 `log2(4096/16)=8` 位，标记 `20-8-4=8` 位。
> 8) `0.9×1 + 0.1×11 = 2.0ns`。
> 9) `0.95×0.9×0.9 = 0.7695`。
> 10) `3000/1.5 = 2000`。
