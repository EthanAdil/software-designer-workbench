08 · 考前必看清单（初版）

初版 2026-11-27（W4），只收已刷五模块：组成、OS、数据结构、程序语言、软件工程；网络、数据库、面向对象待后续阶段补入。公式给适用条件，易混概念给一句区分点；每周模考后增补，考前只翻本文。

一、计算机组成与体系结构

公式 / 结论适用条件与易错
补码范围 −2(n−1) ~ 2(n−1)−1n 位；1000…0 = −2(n−1)，无对应正数
海明码：2k ≥ n + k + 1n 数据位、k 校验位；纠 1 位、检 2 位
IEEE 754：阶码定范围，尾数定精度float 1+8+23，double 1+11+52；偏移量 2(e−1)−1
主存容量 = 存储单元数 × 单元位数地址线位数 = log2(单元数)；按字节编址时单元数 = 容量
执行时间 = 指令数 × CPI ÷ 主频主频先统一为 Hz；MIPS = 主频 ÷ CPI
Cache 平均访问时间 = h × t_C + (1−h) × (t_C + t_M)未命中路径也要先查 Cache，别漏 t_C
流水线总时间 = 首条各段之和 + (n−1) × 最长段各段等长时 = (k+n−1)T；加速比上限 = k
并联可靠度 = 1 − (1−R)n；串联 = ∏R_i并联先取反再乘，串联直接乘；n 个同可靠度才用幂
总线带宽 = 数据线位数 ÷ 8 × 频率32 位 = 4B；位与字节先换算
寻址空间 = 2^地址线根数 × 数据线位数 ÷ 8地址线定范围，数据线定字长；结果按字节
AB区分点
数据总线地址总线一次并行传输位数 vs 可寻址单元数 2n
SRAMDRAM触发器、不刷新、集成度低 vs 电容、需刷新、集成度高
RISCCISC指令精简、硬布线、适合流水线 vs 指令复杂、微程序
中断DMA慢速随机设备、CPU 逐次处理 vs 高速块设备、直接访存

二、操作系统

公式 / 结论适用条件与易错
页内位数 = log2(页大小)；页号位数 = 逻辑地址位数 − 页内位数4KB → 12 位；页号 = 地址 ÷ 页大小 取整
一级索引最大文件 = (块大小 ÷ 索引项) × 块大小1KB/4B = 256 项 → 256KB；二级再乘 256
响应比 = (等待 + 服务) ÷ 服务越大越优先；分子是等待+服务，不是服务时间
周转 = 完成 − 到达；带权周转 = 周转 ÷ 服务先逐作业列完再平均；别忘减到达时间
位示图：字号 = 块号 ÷ 字长；位号 = 块号 mod 字长位号/字号从 0 起；32 位字长即 mod 32
缺页率 = 缺页次数 ÷ 访问次数LRU 手画物理块栈，逐次更新最近使用顺序
PV：互斥初值 1、同步初值 0；P 减 1、V 加 1生产者消费者：mutex=1、empty=N、full=0
AB区分点
页号页内地址地址高位 vs 低位；页大小决定页内位数
响应比周转时间调度优先级 vs 完成−到达
进程线程资源分配单位 vs CPU 调度单位
一级索引二级索引256KB vs 64MB（1KB 块、4B 项）

三、数据结构与算法

公式 / 结论适用条件与易错
二叉树：n0 = n2 + 1；完全二叉树 n 偶 n0 = n/2，n 奇 n0 = (n+1)/2只对二叉树；多叉树不适用
m 阶 B 树：非根非叶关键字 ⌈m/2⌉−1 ~ m−1根至少 1 个；5 阶即 2~4
建堆 O(n)；堆排序整体 O(n log n)建堆自底向上；别把两者混为一个
快排平均 O(n log n)，最坏 O(n²)基本有序/逆序 + 首元素枢轴时最坏
简单选择比较次数 = n(n−1)/2与初始序列无关；移动次数 0~3(n−1)
Dijkstra 单源 O(n²)；Floyd 全源 O(n³) / O(n²)Dijkstra 不能负权；Floyd 可负权、不能负权回路
装填因子 α = 记录数 ÷ 表长α 越大冲突越多、ASL 越大；开放定址 α ≤ 0.75
哈夫曼：WPL = Σ(权 × 路径长度)；n 叶共 2n−1 结点WPL 不是权值和；只有度 0/2 结点
0-1 背包用 DP；分数背包用贪心物品能否分割是分界
AB区分点
建堆堆排序O(n) vs O(n log n)
DijkstraFloyd单源 vs 全源；负权
快排最坏快排平均O(n²) 基本有序 vs O(n log n)
0-1 背包分数背包不可分割 DP vs 可分割贪心
稳定排序不稳定排序插入/冒泡/归并/基数 vs 选择/希尔/快排/堆

四、程序设计语言与编译

公式 / 结论适用条件与易错
编译生成目标代码；解释逐句执行目标代码生成与硬件最密切
中缀 → 前缀/后缀：括号 → 高优先级 → 低优先级操作数顺序不变；前缀运算符在前、后缀在后
传值 = 复制实参值；传址 = 共享地址；传名 = 文本替换传值不改实参；传址改实参
静态类型编译期检查；动态类型运行期检查重载编译期、重写运行期
表达式树：前序 = 前缀，后序 = 后缀，中序 = 中缀中缀要加括号才唯一
编译五阶段：词法 → 语法 → 语义 → 中间代码（含优化） → 目标代码符号表贯穿；目标代码生成最依赖硬件
AB区分点
编译解释生成目标代码 vs 不生成、逐句执行
重载重写同类不同参/编译期 vs 子类覆盖/运行期
传值传址复制值 vs 共享地址
静态绑定动态绑定编译期确定 vs 运行期按对象类型确定

五、软件工程

公式 / 结论适用条件与易错
PERT 期望 = (O + 4M + P) ÷ 6权重 4 给最可能；不是三者平均
关键路径 = 最长路径，总时差 0决定最短工期；可能多条
McCabe V(G) = E − N + 2 = 判定结点 + 1 = 区域数单连通图；三式结果应一致
沟通路径 = n(n−1) ÷ 2n 人两两沟通，不重复计
耦合（低→高）：非直接 < 数据 < 标记 < 控制 < 外部 < 公共 < 内容越低越好
内聚（高→低）：功能 > 顺序 > 通信 > 过程 > 时间 > 逻辑 > 偶然越高越好
维护占比：改善性 > 适应性 > 改正性 > 预防性改善性最大，约 50%+
ISO 9126 六特性：功能、可靠、易用、效率、可维护、可移植不含可扩展性
AB区分点
结构化分析面向对象分析DFD + 数据字典 vs 类图 + 顺序图
时间内聚功能内聚同一时间段执行 vs 单一功能
关键路径最短路径项目最长路径/总时差 0 vs 图的最短路径
判定表/判定树DFD加工逻辑 vs 数据流动（无控制流）
