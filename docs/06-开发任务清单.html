五、维护约定

  • 新增任务：在「待完成」对应优先级表追加一行，写清验收标准与依赖；不要只写「优化题库」这类无法验收的描述。
  • 完成任务：从待完成表删除，移入「已完成」并补完成日期；如产生口径变化，同步更新 README.md 与 docs/00。
  • 数据基线：每次改题库或模块后运行 node tools/check-data.js 与 node tools/check-coverage.js，把最新数字更新到本文「总览」。
  • 本文与代码冲突时，以脚本输出为准，并回头修正本文。
