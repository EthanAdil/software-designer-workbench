二、使用方式（W27）

docs/01 的 W27（2027-05-03 ~ 05-09）安排 2 套历年真题（从已入库八套中选），分三种方式：

  1. 已入库的八套：工作台「真题题库」→ 按年份选 2020 下 / 2021 上 / 2022 上 / 2022 下 / 2023 上 / 2023 下 / 2024 上 / 2024 下整套练习，或按模块筛选；首页「自选真题练习」可把年份、卷型、模块自由组合后生成练习集。点击选项立即判题并按「答案 / 解题思路 / 推导过程」三段显示解析，答错进入独立的真题错题；不影响自编题库的掌握度与模拟考试成绩。2020 上未举办（并入下半年），2021 下题号冲突暂缓，均无套卷可选。
  2. 未入库的 2025 / 2026：只登记来源，年份框显示「待补」且不可勾选；按下面第三节的链接下载 PDF 后离线作答；先做上午卷、再做下午卷，严格计时，不查资料。
  3. 暂缓的 2021 下：公开来源题号体系冲突，未入库；如需练习，按第三节链接自行下载 PDF 离线作答，待取得可核对原卷后补入题库。
  4. 对答案后把反复出现的考点写进「考前必看清单」，并回到工作台对应模块或案例题补练（对照第四节索引）。
  5. 下午卷自评时按 docs/03 的踩分点逐问给分，别只写结论；真题只用于自查与节奏训练，分数不等同于考试预测。

数据结构、分类与自选练习（2026-11-23）

  • 套卷 meta：key / year / half / label / exam / paperType / total / included / count / absent / excluded / source / sourceLabel / answerSource / answerSourceUrl / explanationSource / verified / pending / sourceNote。paperType 目前只有 morning；verified 取 crosschecked / single-source / recalled / pending；pending: true 的套卷只登记来源、count 必须为 0。
  • 题目字段：id / paper / no / year / paperType / kind / module / topic / stem / options[4] / answer / explanation / group / blank / source / sourceUrl / answerSource / answerSourceUrl / explanationSource / explanationUrl / verified。register 会把套卷的年份、卷型、来源、核对状态继承到题目；旧题仍可只写 id/paper/no/module/topic/stem/options/answer/explanation/group/blank，字段兼容。
  • 分类组织：月份套卷（paper）× 年份（year）× 卷型（paperType）× 13 个知识模块（module）。首页「按模块浏览」「按年份浏览」是固定分类；「自选真题练习」是交叉筛选，不改变题目归属。
  • 自选练习流程：首页勾选年份 / 卷型 / 模块 → 选择题量档（全部 / 20 / 30 / 50）→ 实时预览「匹配 N 题，本次抽 M 题」→ 开始进入 #/real?s=1&y=…&t=morning&m=…&n=…。n=0 表示全部匹配题；年份和模块至少各选 1 个；筛选条件存 rk_sd_real_sel。练习内点击选项立即判题，解析下方显示题面/答案/解析来源，题头显示核对状态；小结按模块拆正确率，错题进入独立真题错题。
  • 数据更新方式：在 assets/js/real/ 新增 r-YYYY-MM.js（套卷 meta + RK.real.register），另建 r-explain-YYYY.js 用 RK.real.registerExplanations 注册三段解析（idea 解题思路 / derivation 推导过程 / answer 可省 / selfComposed 标注自编），在 index.html 注册两个脚本，跑 node tools/check-real.js；同步本文件与 docs/平台开发/开发任务清单.md。没有完整题面时不要生成题目，用 pending 套卷登记来源；回忆版/单源题必须如实标注，不把机构答案速对当官方真题。
