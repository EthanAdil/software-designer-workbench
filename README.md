# 软件设计师（软考中级）备考工作台

> **在线使用**：[打开在线工作台 →](https://ethanadil.github.io/software-designer-workbench/)
>
> 电脑或手机浏览器直接访问，无需安装、无需起服务；打卡、作答与成绩保存在当前浏览器。

面向 **2027 年上半年 · 软件设计师** 的个人备考工作台：四阶段 29 周计划、13 个知识模块与 11 篇精讲、607 道自编上午题 + 24 道下午案例、13 套共 445 道历年上午真题，以及阶段测评、模拟考试、错题本与成绩分析。零依赖、纯静态，双击 `index.html` 即可运行；学习数据只留在本机，不上传、不联网。

## 快速开始

**在线版**：直接打开文首的入口链接。

**本地版**：双击 `index.html`（Chrome / Edge / Firefox 均可）。若浏览器限制本地文件脚本，用任意静态服务：

```bash
python -m http.server 8731
# 然后访问 http://localhost:8731
```

8731 是刻意选的冷门端口，避免与本机常驻服务（8080、8000、3000 等）撞车；被占用换任意四位数即可。

> **文档编码**：`docs/` 下 `.md` 是源文件，`.html` 是生成物（改完执行 `node tools/build-docs.js` 刷新）。HTML 已声明 UTF-8，浏览器直接打开 `.html` 不会乱码；直接打开 `.md` 时个别浏览器会按系统 GBK 猜测编码，可能显示乱码。

## 关键功能说明

### 真题题库

- **范围**：13 套上午卷 445 题。2021 下 50 题按本地 PDF OCR 校正转写，2024 上 57 题（其中 46 题由本地 PDF 补入）；2025 / 2026 共 26 题为单源回忆版，保持「待核对」。2020 上未举办，下午卷真题未入库。
- **筛选与练习**：按年份 / 卷型 / 模块自选，题量全部 / 20 / 30 / 50 / 75；整卷练习保持原题号顺序，自选与按模块随机打乱。筛选记忆存 `rk_sd_real_sel`。
- **解析**：每套卷配 `r-explain-*.js`，按「答案 / 解题思路 / 推导过程」三段展示，由 `RK.real.explanationFor(q)` 查询，缺条目时按旧 `explanation` 兜底。
- **数据隔离**：作答写 `rk_sd_real_answers`、错题写 `rk_sd_real_wrong`、每次练习成绩写 `rk_sd_real_scores`，不进入自编键与 `rk_sd_exams`，不影响自编掌握度与模拟考试成绩；答对真题错题自动标「已掌握」。
- **展示约定**：题干填空只留横线，原题号由题头「原题 N」保留；解析中不写选项字母（选项会乱序）。

### 错题本

- 真题错题置顶「重点管理」，自编错题保留原流程；两组统一展示，但统计与备份互不混算。
- 错因复用 `RK.CAUSES` 八类；选定后按 `RK.CAUSE_ADVICE` 自动给出一条结论建议，自由文本「一句话结论」可覆盖。
- 复习三态：待复习 / 复习中 / 已掌握，可手动切换；答错回到「待复习」，答对自动「已掌握」，旧记录的 `resolved` 自动映射。
- 按错因、模块分别计数并画条形统计；打开错题归档页、导出 CSV 也在本页工具栏。
- CSV 列顺序：`题号, 题目, 我的答案, 正确答案, 错因, 一句话结论, 模块, 考点, 错误次数, 状态, 最近错误时间`。文件带 UTF-8 BOM，Excel / WPS 直接打开不乱码；只导出自编错题，真题错题留在 `rk_sd_real_wrong` 单独管理。

### 成绩分析

- 模拟考试与真题成绩折线同屏对照；真题每次练习记录一条：日期 / 模式 / 题量 / 得分率 / 折算 75 分 / 用时 / 模块拆分。
- 模块雷达、成绩分布、薄弱考点下钻与复习建议。
- 自编成绩存 `rk_sd_exams`，真题成绩存 `rk_sd_real_scores`，两类互不混算。

## 数据存储与备份

所有进度存在浏览器 `localStorage`（键前缀 `rk_sd_`），不上传、不联网。

| 类别 | 存储键 | 备份字段 |
| --- | --- | --- |
| 自编作答 | `rk_sd_answers` | `answers` |
| 自编错题（含错因 / 结论） | `rk_sd_wrong` | `wrong` |
| 成绩记录（阶段测评 / 模拟考试） | `rk_sd_exams` | `exams` |
| 计划打卡 | `rk_sd_tasks` | `tasks` |
| 真题作答 | `rk_sd_real_answers` | `realAnswers` |
| 真题错题（含三态） | `rk_sd_real_wrong` | `realWrong` |
| 真题成绩 | `rk_sd_real_scores` | `realScores` |
| 真题筛选记忆 | `rk_sd_real_sel` | `realSel` |
| 练习筛选记忆 | `rk_sd_practice_sel` | `practiceSel` |

`rk_sd_theme` 是界面主题，不属于学习数据，不进备份。

- **导出**：错题本 → 数据管理 →「导出备份（JSON · v2）」。完整导出含全部 9 类；选择性导出只含勾选类别。
- **备份格式 v2**：根字段 `_meta`（`format`、`version`、`mode`、`categories`、`schema` 字段说明）+ `exportedAt` + 按需包含的数据类别，字段说明随文件保存，换设备也能读懂结构。
- **导入**：按备份中的类别覆盖，未包含的类别保持本机不变；覆盖前有确认弹窗。兼容旧版四字段备份（无 `_meta`，按 v1 处理）；逐类校验格式、写入后回读核对，失败回滚并提示；版本不支持或类别未知时拒绝导入。
- **归档**：按 `progress/YYYY/YYYY-MM-DD.json` 保存，归档脚本为 `node tools/archive-progress.js <备份文件>`。脚本要求 `answers` / `wrong` / `exams` / `tasks` 四类齐全，请用「完整导出」的文件归档；选择性备份只用于跨设备补数据，不要作为唯一快照。目录与命名约定见 `progress/README.md`。
- **节奏**：建议每周导出一次；阶段测评、模拟考试当天额外导出并加后缀。换浏览器或清缓存会丢失，无痕模式下数据不落盘。

## 建议的使用节奏

**每天（约 2 小时）**

1. 打开「总览」，看本周任务与今日待办；
2. 按计划执行 1 个学习块 + 1 次刷题（20 题左右）；
3. 错题当天进错题本，标注错因类型。

**每周（周末半天）**

1. 补完本周未打卡任务；
2. 做 1 次「自选模块练习」，只勾本周所学模块（题量按上午卷权重折算）；
3. 回看错题本中本周新增的题，重做一遍并导出备份。

**每阶段结束**

1. 做对应「阶段测评」，看模块得分表；
2. 正确率 < 60% 的模块回到「知识模块」重看要点，补练该模块题库全部题目；
3. 达标后再进入下一阶段。

**冲刺期（W25 起）**

每周 2 套模拟考试，严格 120 分钟不查资料；考后 1 小时内完成复盘并更新「考前必看清单」。

## 扩展与维护

### 新增自编题

在 `assets/js/bank/` 下新增文件，按现有格式注册：

```js
(function (RK) {
  RK.registerQuestions([{
    id: 'CS-999',                  // 全局唯一，示例按实际编号替换
    module: 'computer-system',     // 必须是 RK.MODULES 中的 key
    topic: '数据表示',
    difficulty: 2,                 // 1~3
    stem: '题干……',
    options: ['A 项', 'B 项', 'C 项', 'D 项'],
    answer: 0,                     // 正确项下标，从 0 开始
    explanation: '解析……',
    tags: ['计算']
  }]);
})(window.RK);
```

再在 `index.html` 加一行 `<script src="assets/js/bank/xxx.js"></script>`。下午案例题用 `RK.registerAfternoon`，字段为 `type`（`dfd` / `uml` / `db` / `algo` / `java` / `cpp`）、`background`、`questions[{q, score, answer}]`、`tips`。

### 新增真题套卷

在 `assets/js/real/` 下新增套卷文件，按现有格式注册：

```js
(function (RK) {
  RK.real.registerPaper({
    key: '2027-05', year: 2027, half: '上半年', label: '2027 年上半年',
    exam: '软件设计师（中级）· 上午卷（综合知识）', paperType: 'morning',
    total: 75, included: 0, absent: '', excluded: '', pending: false,
    source: '题面链接', sourceLabel: '题面来源',
    answerSource: '答案来源', answerSourceUrl: '答案链接',
    explanationSource: '解析来源', verified: 'single-source'
  });
  RK.real.register([{
    id: 'ZR-2027-05-001', paper: '2027-05', no: 1,
    module: 'computer-system', topic: '存储系统',
    stem: '题干……', options: ['A', 'B', 'C', 'D'], answer: 0,
    explanation: '解析……', group: 1, blank: 0,
    source: '题面来源', answerSource: '答案来源', verified: 'single-source'
  }]);
})(window.RK);
```

再在 `index.html` 的真题脚本区注册。`module` 必须是 `RK.MODULES` 中的 key；真题 id 统一用 `ZR-<套卷>-<三位题号>`，不要与自编题库混用。题干填空只写横线、不写题号数字，原题号由 `no` 字段保留。套卷的 `count` 由已注册题目数自动累计，`included` 记录原卷实收题数，无需手写 `count`。

多空题按现有结构拆成多条记录：同一组记录的 `stem` 与 `group` 必须一致，`group` 填总空数，`blank` 填第几空（1 起）；每条记录都保留全部横线，按从左到右对应 `blank`，`options` / `answer` 只写当前空。

### 新增三段解析

另建 `assets/js/real/r-explain-<套卷>.js`，用 `RK.real.registerExplanations({ '<题目id>': { idea, derivation, answer?, source?, selfComposed? } })` 注册。`idea` 为解题思路、`derivation` 为推导过程，`answer` 可省略（自动取正确选项文本）；缺条目时按旧 `explanation` 兜底。解析中不写选项字母引用（选项会乱序），并在 `index.html` 注册解析脚本。

### 新增页面或文档

- **页面**：在 `assets/js/views-*.js` 用 `RK.router.add` 注册路由，在 `index.html` 引入脚本并加入侧栏导航。
- **备考文档**：在 `docs/` 新增 `.md`，运行 `node tools/build-docs.js` 生成 HTML，并在 `assets/js/views-docs.js` 的文档清单中登记；工作台自身文档放 `docs/平台开发/`，不生成 HTML、不进导航。

### 数据质量与校验

- `verified` 取 `crosschecked`（已核对）/ `single-source`（题面与答案不同源）/ `recalled`（回忆版）/ `pending`（待补）。只有答案、没有完整题面的套卷用 `pending: true` 登记来源，不注册题目（`count` 自动为 0）；题面与答案必须可核对，不猜题、不补造。
- 新增 / 修改套卷后同步 `docs/07-历年真题来源与考点索引.md` 的来源与缺口表，并更新本 README 的「内容现状」。
- 提交前运行：

```bash
node tools/check-data.js
node tools/check-coverage.js --strict
node tools/check-real.js
node tools/check-render.js
node tools/build-docs.js   # 改过 docs/*.md 后
```

`check-data.js` 校验 id 重复、答案越界、组卷题数、计划完整性与模块—要点—文档口径；`check-coverage.js` 校验要点覆盖、题量是否够权重 ×3/×5 与模拟考试重复率；`check-real.js` 校验真题题量、来源分级、模块覆盖、三段解析与自编题库隔离。线上入口由 GitHub Pages 从 `master` 根目录发布，推送后 1~2 分钟更新。

## 术语与口径

全项目以源码为基准，README、文档、界面提示与代码注释统一用词；历史归档中的旧措辞保留原文。

| 概念 | 统一用词（源码基准） | 说明 |
| --- | --- | --- |
| 项目自称 | 工作台 | 不用「平台 / 站点 / 本系统」 |
| 题库 | 自编题库（`RK.bank`）/ 真题题库（`RK.real`） | 不单独用「题库」指自编 |
| 真题 | 历年真题 / 真题题库 | 不用「近年真题」「真题卷」 |
| 错题 | 错题本（功能页）/ 错题记录（数据条目） | 不用「错题集 / 错题库」 |
| 笔记 | 错因、一句话结论 | 「归因」只作动作，不作字段名 |
| 打卡 | 计划打卡（`rk_sd_tasks`） | 不用「任务打卡」 |
